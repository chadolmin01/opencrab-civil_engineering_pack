## 2. 하천 계획 기준 — 설계 홍수빈도 (KDS 51 12 05)

### 2.1 하천 등급별 설계 홍수 재현기간 (T_r)
| 하천 등급 | 유역 면적 기준 | 설계 재현기간 T_r (년) |
|---------|-------------|---------------------|
| 국가하천 (대하천) | 유역 면적 ≥ 500 km² | 200년 |
| 국가하천 (중하천) | 유역 면적 200 ~ 500 km² | 100년 |
| 지방하천 (1급) | 유역 면적 50 ~ 200 km² | 100년 |
| 지방하천 (2급) | 유역 면적 10 ~ 50 km² | 50년 |
| 소하천 | 유역 면적 < 10 km² | 30년 ~ 50년 |
| 도시 배수로 | — | 10년 ~ 30년 |

### 2.2 여유고 (Freeboard, F) — 제방 마루 최소 여유고
| 계획홍수량 Q (m³/s) | 최소 여유고 F (m) |
|-----------------|----------------|
| Q < 200 | 0.6 |
| 200 ≤ Q < 500 | 0.8 |
| 500 ≤ Q < 2,000 | 1.0 |
| 2,000 ≤ Q < 5,000 | 1.2 |
| 5,000 ≤ Q < 10,000 | 1.5 |
| Q ≥ 10,000 | 2.0 |

### 2.3 설계 홍수량 산정 — 합리식
```
Q = (1/3.6) × C × I × A
```
- Q: 첨두홍수량 (m³/s)
- C: 유출계수 (불투수 시가지 0.70 ~ 0.95, 산지 0.20 ~ 0.45)
- I: 강우강도 (mm/hr) — 티센 평균 또는 Talbot 공식 적용
- A: 유역 면적 (km²)

## 3. 제방 설계 기준 (KDS 51 15 05)

### 3.1 제방 표준 단면 — 제방 마루 폭 (B_top)
| 계획홍수량 Q (m³/s) | 최소 제방 마루 폭 B_top (m) |
|-----------------|------------------------|
| Q < 200 | 3.0 |
| 200 ≤ Q < 500 | 4.0 |
| 500 ≤ Q < 2,000 | 5.0 |
| 2,000 ≤ Q < 5,000 | 6.0 |
| Q ≥ 5,000 | 7.0 이상 (관리도로 포함 시 8.0) |

### 3.2 제방 법면 경사 (비탈면 기울기)
| 제방 재료 | 제내지측 법면 경사 (수평:수직) | 제외지측 법면 경사 |
|---------|------------------------|----------------|
| 점성토 | 1:2.0 이상 | 1:2.0 이상 |
| 사질토 | 1:3.0 이상 | 1:2.0 이상 |
| 혼합토 | 1:2.5 이상 | 1:2.0 이상 |
- 기초 지반이 연약한 경우: 안정 해석(원호활동 안전율) 별도 수행

### 3.3 제방 안정 검토 — 원호활동 안전율 (F_s)
| 검토 조건 | 최소 안전율 F_s |
|---------|------------|
| 평상시 침투 (정상 침투) | ≥ 1.5 |
| 급격한 수위 저하 | ≥ 1.2 |
| 지진 시 (kh = 0.15) | ≥ 1.1 |

### 3.4 제방 침투 안정 검토 (파이핑·침식)
- 허용 동수경사: i_allow ≤ 0.5 / F_s (F_s ≥ 2.0 권고)
- 침투 해석 도구: 유선망 또는 FEM 침투 해석
- 필터 설계: Terzaghi 필터 기준 적용
  - D₁₅(필터) / D₈₅(기초재) ≤ 4 ~ 5
  - D₁₅(필터) / D₁₅(기초재) ≥ 4 ~ 5

## 4. 호안 설계 기준 (KDS 51 20 10)

### 4.1 허용 유속 — 제방 피복 재료별
| 피복 재료 | 허용 유속 V_allow (m/s) |
|---------|----------------------|
| 식생 (잔디) | ≤ 1.5 |
| 돌망태 (Gabion) | ≤ 3.0 |
| 사석 (Riprap) | ≤ 4.0 |
| 콘크리트 블록 | ≤ 5.0 |
| 현장 타설 콘크리트 | ≤ 6.0 |

### 4.2 사석 크기 산정 (Isbash 공식)
```
D_50 = V² / (2g × (s_s - 1) × C_s²)
```
- D_50: 사석 중앙 입경 (m)
- V: 설계 유속 (m/s)
- s_s: 사석 비중 (일반 화강암 ≈ 2.65)
- C_s: Isbash 계수 (무작위 투하 0.86, 밀실 부설 1.20)

## 5. 보(洑) 설계 기준 (KDS 51 40 10)

### 5.1 고정보 월류 공식 (전폭 위어, 완전 월류)
```
Q = C_d × L × H^(3/2)
```
- Q: 월류량 (m³/s)
- C_d: 유량계수 (보통 1.70 ~ 2.10, 예봉 위어 ≈ 1.87)
- L: 위어 유효 폭 (m)
- H: 위어 상류 수두 (m)

### 5.2 보 구조 안정 검토 항목
| 안정 항목 | 최소 안전율 |
|---------|----------|
| 전도 안정 (F_OT) | ≥ 1.5 (홍수 시 1.2) |
| 활동 안정 (F_SL) | ≥ 1.5 (홍수 시 1.2) |
| 지지력 (F_bearing) | 최대 접지압 ≤ 허용 지지력 |
| 양압력 (Uplift) | 유선망 기반 계산, 배수공 설치 |

## 6. 하천 수리 계산 기준

### 6.1 Manning 공식 — 평균 유속
```
V = (1/n) × R^(2/3) × S^(1/2)
```
- V: 평균 유속 (m/s)
- n: Manning 조도계수
- R: 동수반경 = A/P (m)
- S: 에너지 경사 (= 수면 경사, 등류 가정)

### 6.2 주요 조도계수 (n) 값
| 수로 종류 | n 범위 | 설계 대표값 |
|---------|-------|----------|
| 현장 타설 콘크리트 수로 | 0.012 ~ 0.016 | 0.013 |
| 석축 수로 | 0.017 ~ 0.030 | 0.025 |
| 자연 하천 (직선, 청결) | 0.025 ~ 0.033 | 0.030 |
| 자연 하천 (사행, 잡초) | 0.035 ~ 0.050 | 0.040 |
| 범람원 (농경지) | 0.025 ~ 0.035 | 0.030 |
| 범람원 (수목 밀생) | 0.080 ~ 0.150 | 0.100 |

### 6.3 프루드 수 (Froude Number) 기준
```
Fr = V / sqrt(g × D)   (D: 수리 평균 수심)
```
- Fr < 1.0: 상류 (Subcritical) — 일반 하천 설계 기준
- Fr = 1.0: 한계류
- Fr > 1.0: 사류 (Supercritical) — 에너지 소산 구조물 필요

## 7. 환경 수리 기준

### 7.1 저수호안 및 생태 하천 설계
- 저수 호안 비탈 경사: 1:3 이상 (생태 이동 통로 확보)
- 하천 유지유량: 갈수량(Q_355) 기준, 통상 기준 유량의 10 ~ 20 % 이상 확보
- 어도(魚道) 설치 기준: 낙차 0.3 m 이상 보(洑)·댐에 설치 의무화

### 7.2 하천 환경 용량 지표
| 지표 | 기준치 |
|----|------|
| 자정 계수 (k₂/k₁) | 자정 능력 양호: ≥ 1.5 |
| 하천 DO 최저 허용값 | ≥ 5.0 mg/L (생활환경 기준 Ib등급) |
| BOD 허용 농도 | ≤ 3 mg/L (Ib등급), ≤ 1 mg/L (Ia등급) |
