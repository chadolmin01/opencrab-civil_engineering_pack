# KOSHA GUIDE W-1 석면 해체·제거 작업 안전 지침 — 출처: 한국산업안전보건공단(KOSHA) 기술지침 / 산안법 제119~122조 / 석면안전관리법 기반 — 수집일: 2026-05-28

## 개요

석면(Asbestos)은 IARC 발암물질 1군으로 지정된 물질로, 1급 발암물질인 석면 섬유의 흡입은 중피종(mesothelioma)·석면폐·폐암을 유발한다. 산업안전보건법 제119조는 기관 조사 의무 대상(석면 함유율 1 % 이상, 면적 50 m² 이상 건축물)을 규정하며, 해체·제거 작업은 석면 해체·제거 전문업체가 수행해야 한다. KOSHA GUIDE W-1은 해체 절차·음압 시스템·폐기물 처리·잔류 농도 기준 등 실무 정량 기준을 제시한다.

---

## 정량 기준

### 기관 조사(석면 조사) 의무 기준

| 조건 | 의무 여부 |
|---|---|
| 석면 함유율 **1 wt% 이상** 재료 사용 건축물 | 기관 조사 의무 |
| 연면적 **50 m² 이상** 건축물 철거·대수선 | 기관 조사 의무 |
| 슬레이트 지붕재, 텍스 천장재, 보온재 포함 건축물 | 석면 함유 추정 → 기관 조사 |

### 작업장 잔류 농도 기준

| 기준 항목 | 기준값 |
|---|---|
| 석면 해체 완료 후 잔류 농도 (공기 중) | **0.01 개/cc (f/cc)** 이하 확인 후 격리 해제 |
| 작업 중 근로자 노출 허용 기준 (8시간 TWA) | **0.1 f/cc** 이하 |
| 작업 구역 외부 비산 농도 | **0.01 f/cc** 이하 유지 |

### 음압 격리 시스템

| 항목 | 기준값 |
|---|---|
| 작업 구역 내부 음압 유지 | 외부 대비 **-5 Pa 이상** 음압 |
| HEPA 필터 효율 | **99.97 %** 이상 (0.3 μm 입자 기준) |
| 음압기 가동 중 공기 교환 횟수 | 시간당 **4회 이상** |
| 출입 에어락(Air Lock) 전실 | 최소 2중 격리 구조 |

### 폐기물 처리

- 석면 함유 폐기물: 이중 포장(내부 비닐백 0.12 mm 이상, 외부 견고 용기)
- 폐기물 표지: 「석면 함유 폐기물」 경고 표지 부착
- 매립: 지정 폐기물 매립 시설(석면 전용 셀) 처리

## 검사·시험 방법

### 석면 조사 방법

1. 예비 조사: 건축 도면·사용 자재 검토 → 석면 함유 의심 자재 목록화
2. 시료 채취: 의심 자재 1개소당 3개 이상 시료 (면적 1,000 m² 초과 시 추가)
3. 분석: 편광현미경(PLM) 또는 전자현미경(TEM) — 석면 종류 및 함유율 판정
4. 석면 지도 작성: 위치·종류·면적·상태 등급 기재

### 작업 중 공기 농도 측정

1. 개인 시료: 작업 근로자 부착, 위상차 현미경(PCM) 분석 — **6시간 이상** 포집
2. 지역 시료: 작업 구역 내·외부 각 1개소 이상
3. 해체 완료 후 잔류 농도: 시료 5개 이상, 전자현미경(TEM) 또는 위상차 현미경으로 분석

### 보호구 기준

| 항목 | 기준 |
|---|---|
| 호흡 보호구 | 전동식 방진 마스크(PAPR) 또는 전면 공기 공급식(SAR) — 1등급 방진 필터 |
| 방호복 | 1회용 타이벡(Tyvek) 슈트 (석면 분진 투과 방지) |
| 장갑 | 석면 관통 방지 1회용 |

## 합격 기준

| 검사 항목 | 합격 기준 |
|---|---|
| 잔류 농도 | **0.01 f/cc** 이하 (5개 시료 평균) |
| 음압 유지 | 외부 대비 -5 Pa 이상 지속 |
| HEPA 필터 | 교체 주기 준수 및 차압 이상 없음 |
| 폐기물 이중 포장 | 내부백 파손 없음, 경고 표지 부착 |
| 작업자 노출 | TWA ≤ 0.1 f/cc |

## 관련 표준 인용

- 산업안전보건법 제119~122조 및 시행규칙 (석면 조사·해체 전문업 등록)
- 석면안전관리법 제22·23조 (슬레이트 건축물 관리·해체)
- 고용노동부 고시 「석면 조사 및 석면 해체·제거 안전관리에 관한 기준」
- KOSHA GUIDE W-1 (본 지침 원문)
- ISO 16000-7 공기 중 석면 섬유 수 측정법
