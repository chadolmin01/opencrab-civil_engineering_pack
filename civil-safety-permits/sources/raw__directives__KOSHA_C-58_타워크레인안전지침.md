# KOSHA GUIDE C-58 타워크레인 설치·사용 및 해체작업 안전지침 — 출처: 한국산업안전보건공단(KOSHA) 기술지침 / 산업안전보건기준에 관한 규칙 기반 — 수집일: 2026-05-28

## 개요

타워크레인은 건설 현장 중대재해 발생 원인 2위에 해당하는 고위험 양중 장비다. KOSHA GUIDE C-58은 타워크레인의 설치·상승(텔레스코핑)·해체·운용 전 단계에 걸친 안전 관리 기준을 규정한다. 적용 대상은 정격 하중 0.5 t 이상 모든 타워크레인이며, 산업안전보건법 제38·39·63조, 건설기계관리법, 고용노동부 고시 「건설기계 안전 기준에 관한 규칙」과 연동된다.

---

## 정량 기준

### 설치 이격 거리

| 항목 | 기준값 |
|---|---|
| 작업 반경 내 장애물 이격 | 붐 끝에서 수평 2 m 이상 |
| 인접 타워크레인 작업 반경 중첩 시 상부 크레인 붐 높이 차 | 최소 2 m 이상 |
| 건물 외벽·비계와의 최소 수평 이격 | 0.6 m 이상 |
| 앵커(벽체 고정) 간격 | 제조사 사양 이하, 통상 최대 자립 높이 초과 전 1단 설치 |

### 풍속 한계

| 작업 종류 | 순간 최대 풍속 한계 |
|---|---|
| 설치·해체·텔레스코핑 | 10 m/s 초과 시 즉시 중지 |
| 일반 양중 작업 | 15 m/s 초과 시 중지 |
| 크레인 계류(비작업 시) | 30 m/s 초과 시 훅 블록 고정, 슬루잉 브레이크 해제하여 자유선회 |

### 하중 및 구조

| 항목 | 기준값 |
|---|---|
| 과부하 방지장치 작동 설정 | 정격 하중의 105 % 이하에서 자동 차단 |
| 모멘트 리미터 | 정격 모멘트의 110 % 초과 시 자동 정지 |
| 마스트 수직도 | 전체 높이 대비 1/1 000 이내 (예: 높이 50 m → 편차 ≤ 50 mm) |
| 텔레스코핑 중 최대 허용 편하중 | 제조사 기준, 일반적으로 0 (무부하 상태 유지) |

### 전도 방지

- 설치·해체 중 기초 앵커볼트 체결 토크 값은 제조사 지정값 ±10 % 이내로 유지
- 자립 높이 초과 전 벽체 앵커(타이 프레임) 선행 설치 의무
- 기초 지반 지지력: 타워크레인 설치 전 지반 조사 실시, 설계 지내력 ≥ 제조사 요구값

## 검사·시험 방법

### 설치 전 자체 검사

1. 마스트 핀·볼트 체결 상태 육안 확인 (크랙·변형·부식 여부)
2. 로프 지름 감소율 측정: 공칭 지름 대비 7 % 이상 감소 또는 소선 끊김 6 % 이상 시 즉시 교체
3. 과부하 방지장치, 권과 방지장치, 비상정지장치 기능 시험 (무부하·정격 하중 각 1회)
4. 안전밸브·유압 작동 압력: 설정 압력 ±5 %

### 작업 중 점검

- 매일 작업 전 안전장치 작동 확인 (5분 점검표 기록)
- 강풍·폭우 후 재개 전 구조부 이상 여부 점검
- 주간 단위: 로프·드럼 마모, 훅 안전 걸쇠 작동, 전기 절연 저항 (≥ 1 MΩ)

### 정기 검사 (법정)

- 최초 설치 후 및 이후 **6개월마다** 건설기계 검사기관 정기 검사
- 임대 후 현장 이전 시 재설치 검사 의무

## 합격 기준

| 검사 항목 | 합격 기준 |
|---|---|
| 과부하 방지장치 | 정격 하중 105 % 이하 자동 차단 확인 |
| 권과 방지장치 | 훅 최고점 0.25 m 이상 여유 확보 |
| 비상정지 | 작동 후 2 s 이내 정지 |
| 마스트 수직도 | 1/1 000 이내 |
| 와이어로프 절단 하중 | 최대 사용 하중 × 안전율 5 이상 |

## 접근 통제

- 타워크레인 작업 반경 내 근로자 출입을 통제하는 신호수 1인 이상 배치 의무
- 신호 체계: 무전기 또는 수신호 (신호 체계 사전 교육, 기록 유지)
- 하부 작업 중지 구역 반경: 양중 하물 최대 치수 + 낙하 반경 (안전계수 1.5 적용)

---

## 해체 절차

1. 해체 계획서 작성 (자격자 서명) 및 발주처·감리 사전 승인
2. 해체 당일 풍속 10 m/s 초과 시 작업 중지
3. 역순 해체: 텔레스코핑 단계별 마스트 제거 → 지브·카운터지브 → 마스트 기초 철거
4. 해체 중 크레인 반경 내 모든 작업 중단, 출입 차단 펜스 설치
