# KOSHA GUIDE W-9 화학물질 물질안전보건자료(MSDS) 관리 및 근로자 교육 지침 — 출처: 한국산업안전보건공단(KOSHA) 기술지침 / 산안법 제114~116조 / GHS 기반 — 수집일: 2026-05-28

## 개요

건설 현장에서 사용되는 에폭시 수지, 유기용제(자일렌·톨루엔·MEK), 시멘트 분진, 우레탄 발포제, 방청 도료 등은 GHS(Globally Harmonized System) 기준 유해화학물질로 분류된다. KOSHA GUIDE W-9은 산업안전보건법 제114조(물질안전보건자료 작성·제공)~제116조(교육) 및 고용노동부 고시 「화학물질의 분류·표시 및 물질안전보건자료에 관한 기준」에 따른 MSDS 비치·교육·노출 관리 실무 기준을 규정한다.

---

## 정량 기준

### GHS 유해성 분류 — 주요 건설 화학물질

| 물질 | GHS 유해성 구분 | 주요 위험 |
|---|---|---|
| 에폭시 수지 (비스페놀 A형) | 피부 과민성 1구분, 눈 자극 2구분 | 피부 감작, 호흡기 과민 |
| 자일렌(Xylene) | 인화성 액체 3구분, 흡인 유해성 1구분 | 화재·폭발, 중추신경 억제 |
| 톨루엔 | 인화성 액체 2구분, 생식독성 2구분 | 화재, 태아 독성 |
| 시멘트 분진 (결정형 유리규산) | 발암성 1A구분 | 규폐증, 폐암 |
| 우레탄 도료 경화제(이소시아네이트) | 호흡기 과민성 1구분 | 직업성 천식 |

### 노출 한계 (OEL)

|---|---|---|
| 자일렌 | **100 ppm** | 150 ppm |
| 톨루엔 | **50 ppm** | 100 ppm |
| 메틸에틸케톤(MEK) | 200 ppm | 300 ppm |
| 결정형 유리규산(호흡성) | **0.05 mg/m³** | — |
| 에폭시 수지 분진 | **0.5 mg/m³** | — |
| 이소시아네이트 (TDI) | **0.005 ppm** | 0.02 ppm |

### MSDS 비치 기준

- 해당 화학물질 취급 작업 장소에 **인쇄본 또는 전자 단말 형태**로 상시 열람 가능하도록 비치
- MSDS 갱신 주기: 최초 작성 후 **5년마다** 재검토·갱신 (성분·독성 변경 시 즉시 갱신)
- 혼합물 MSDS 작성: 함유 성분이 1 wt% 이상(발암물질 0.1 wt% 이상)인 경우 기재 의무

## 검사·시험 방법

### 작업 환경 측정

- 유해화학물질 취급 작업: **6개월마다** 작업 환경 측정 (노출 초과 이력 있을 시 3개월마다)
- 측정 방법: NIOSH/OSHA 방법 또는 고용노동부 고시 작업 환경 측정·분석 방법
- 측정 결과 기록 보존 기간: **30년** (발암물질)·**5년** (기타)

### 근로자 노출 모니터링

1. 개인 시료 포집기(PBZ sampler) 부착 후 1교대 전체 (6~8시간) 포집
2. 분석: 가스 크로마토그래피(GC-FID/MS), 중량법(분진)
3. 측정값 ≥ 노출 기준의 50 % 시 개선 조치 및 공학적 제어 검토 의무

### 교육 기준

| 교육 종류 | 대상 | 최소 시간 |
|---|---|---|
| 신규 채용 시 MSDS 교육 | 화학물질 취급 신규 근로자 | 1시간 이상 |
| 작업 내용 변경 시 추가 교육 | 해당 근로자 | 1시간 이상 |
| 정기 교육 | 화학물질 취급 근로자 전원 | 연 2회 이상 |
