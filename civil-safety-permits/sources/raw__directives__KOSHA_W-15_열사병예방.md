# KOSHA GUIDE W-15 온열 질환 예방을 위한 작업 관리 지침 — 출처: 한국산업안전보건공단(KOSHA) 기술지침 / 고용노동부 폭염 작업 관리 지침 기반 — 수집일: 2026-05-28

## 개요

건설 현장 옥외 작업자는 하절기 온열 질환(열사병·열탈진·열경련·열부종) 고위험군이다. 열사병(Heat Stroke)은 체온 조절 기능 마비로 핵심 체온이 40 ℃ 이상 상승하는 의료적 응급 상황으로, 미처치 시 사망률이 50 % 이상이다. KOSHA GUIDE W-15는 WBGT(습구흑구온도) 지수를 기반으로 작업·휴식 비율, 온도별 작업 제한 기준, 수분·염분 보충, 그늘 휴식 시설 설치 기준을 규정한다.

---

## 정량 기준

### WBGT(습구흑구온도) 산출

> WBGT (옥외) = 0.7 × 자연 습구온도 + 0.2 × 흑구온도 + 0.1 × 건구온도

### WBGT 기준 작업·휴식 관리표

| WBGT (℃) | 대기온도 참고 (상대습도 60 % 기준) | 조치 |
|---|---|---|
| **< 28** | < 31 ℃ | 정상 작업, 수분 섭취 강조 |
| **28 ~ 30** | 31 ~ 33 ℃ | 작업 75 % / 휴식 25 % (45분 작업 → 15분 휴식) |
| **30 ~ 32** | 33 ~ 35 ℃ | 작업 50 % / 휴식 50 % (30분 작업 → 30분 휴식) |
| **32 ~ 35** | 35 ~ 38 ℃ | 작업 25 % / 휴식 75 % (15분 작업 → 45분 휴식) |
| **≥ 35** | ≥ 38 ℃ | **옥외 작업 중지 권고** |

### 기온 단독 기준 (WBGT 측정 불가 시)

| 대기 온도 | 고용노동부 조치 기준 |
|---|---|
| **33 ℃ 이상** | 옥외 작업 시 매 시간 10분 이상 그늘 휴식 |
| **35 ℃ 이상** | **옥외 작업 제한** (오후 2~5시 중 위험 작업 중지 권고) |
| **38 ℃ 이상** | 폭염 특보 발령 → 작업 중지 또는 탄력적 근무(조조 출근) |

### 수분·염분 보충 기준

| 항목 | 기준값 |
|---|---|
| 작업 중 음용수 제공 | **15~20분마다 약 200 mL** (1컵) |
| 염분 보충 (전해질 음료) | 땀 분비 과다 시 0.1 % 식염수 또는 스포츠 음료 병행 |
| 알코올·카페인 음료 | 이뇨 효과로 탈수 가속 → 금지 |
| 1일 수분 목표 섭취량 | 작업 강도에 따라 **1.5 ~ 4 L** |

### 그늘 휴식 시설 기준

| 항목 | 기준값 |
|---|---|
| 그늘막 설치 | 근로자 10인당 그늘 면적 **6 m²** 이상 |
| 이동 거리 | 작업 위치에서 휴식 시설까지 **150 m 이내** |
| 쿨링 시설 | 기온 35 ℃ 이상 시 선풍기·냉방 장치 또는 차가운 물 제공 |

## 검사·시험 방법

### WBGT 측정

1. 측정 장비: WBGT 미터(자연 습구·흑구·건구 온도계 일체형) 사용
2. 측정 위치: 작업 구역 내 직사광선 아래 (실외) 또는 작업 환경 내 복사열 대표 지점
3. 측정 주기: 작업 시작 전, 오전·오후 각 1회 이상 (오전 11시·오후 2시 기준)
4. 기록: 측정값·측정자·조치 내용 일지에 기록

### 온열 질환 징후 모니터링

- 관리 감독자는 근로자 2인당 1인 비율로 **짝 제도(buddy system)** 운영
- 체온 측정: 귀 체온계로 38 ℃ 초과 시 즉시 작업 중단·응급 처치
- 열사병 응급 처치: 체온 39 ℃ 미만으로 낮추는 것을 목표로 냉수 스프레이·젖은 수건 적용 후 즉시 119 신고

### 신규 근로자 순응 기간

| 기간 | 작업 강도 제한 |
|---|---|
| 1~3일차 | 최대 작업 능력의 **50 %** |
| 4~7일차 | 최대 작업 능력의 **75 %** |
| 8일 이후 | 정상 작업 가능 |

## 합격 기준 (현장 점검 체크리스트)

| 점검 항목 | 합격 기준 |
|---|---|
| WBGT 측정·기록 | 작업 시간 중 2회 이상 측정·기록 |
| 음용수 비치 | 15~20분 간격 제공 가능 냉수(20 ℃ 이하) 확보 |
| 그늘 휴식 시설 | 작업 반경 150 m 이내, 10인당 6 m² 이상 |
| 응급 연락 체계 | 119 번호 및 최인근 병원 경로 게시 |
| 온열 질환 예방 교육 | 작업 시작 전 근로자 전원 교육 기록 확인 |
