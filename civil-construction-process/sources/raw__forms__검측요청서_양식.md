# 검측요청서 (별지 제6호 서식 — 검측요청·결과 통보내용) — 발행기관: 국토교통부 (건설사업관리 업무지침서 / 시공감리업무요령 별지서식) — 출처: https://www.law.go.kr/LSW/flDownload.do?flSeq=116505117 (별지 6 검측요청·결과 통보내용) — 수집일: 2026-05-28

## 개요
한국 모든 공공·민간 건설현장에서 사용되는 표준 검측 절차의 핵심 문서.
시공자가 자체점검 완료 후 책임감리원(또는 건설사업관리기술자)에게 검측을 요청할 때 제출.

## 검측 업무 절차 (표준 흐름)
1. 현장시공 완료
2. 시공자 담당기술자 자체 점검 (체크리스트 작성)
3. 검측요청서 제출 (이 문서)
4. 책임감리원(건설사업관리기술자) 검측 수행
5. 검측결과 통보 (적합/부적합)
   - 적합 시: 다음 단계 공정 착수
   - 부적합 시: 부적합 시정지시서 통보 → 재시공/보완
6. 일반사항: 검측결과 통보서 발급

[1. 표제부]
- 문서번호: ____________ (예: 검측-2026-001)
- 수신: 책임감리원 (또는 감리단장)
  - 입력 타입: 텍스트
- 발신: 시공자 현장대리인
  - 입력 타입: 텍스트
- 작성일자: ____________
  - 입력 타입: 날짜 (YYYY-MM-DD)

[2. 공사 일반정보]
- 공사명: ____________
  - 입력 타입: 텍스트
  - 예시값: "○○○ 아파트 신축공사" / "△△ 고속국도 ○공구"
- 발주처: ____________
  - 입력 타입: 텍스트
  - 예시값: 한국토지주택공사 / 한국도로공사 / 국가철도공단
- 시공사: ____________
  - 입력 타입: 텍스트
- 감리단(건설사업관리용역사): ____________
  - 입력 타입: 텍스트

[3. 검측 대상]
- 위치 및 공종: ____________
  - 입력 타입: 텍스트
  - 예시값: "지하 2층 기둥 C1~C8, 철근배근"
- 세부공종: ____________
  - 입력 타입: 텍스트
  - 예시값: 철근 / 거푸집 / 콘크리트타설 / 항타 / 토공 / 흙막이
- 검측부위: ____________
  - 입력 타입: 텍스트 (구간/위치 좌표)
- 공사량(수량): ____________
  - 입력 타입: 숫자 + 단위 (m³, m, 본 등)
- 검측요구일시: ____________
  - 입력 타입: 일시 (YYYY-MM-DD HH:MM)
- 검측 항목 (사항): ____________
  - 입력 타입: 텍스트 (다중)

[4. 첨부 (시공자 사전제출 자료)]
- 시공자 시공점검표(자체 체크리스트): 첨부 (필수)
- 자체점검 결과: 첨부 (필수)
- 시험성과표(레미콘 송장, 철근 시험성적서 등): 첨부 (해당 시)
- 시공자 작성 야장(작업일지): 첨부
- 시공도면(샵드로잉): 첨부

[5. 검측 결과 (감리원 작성란)]
- 검측일시: ____________ (입력 타입: 일시)
- 검측 방법: 육안 / 측정 / 시험 / 입회
- 검측 결과: 적합 / 부적합 (체크박스)
- 부적합 사유 및 조치사항: ____________ (입력 타입: 텍스트, 부적합 시 필수)
- 재검측 요청일시: ____________ (부적합 시)

[6. 서명란]
- 시공자 (자격: 시공기술자 / 현장대리인): ____________ (인)
  - 자격요건: 건설기술인 (해당 분야 중급 이상이 일반적)
- 검측자 (자격: 건설사업관리기술자 / 감리원): ____________ (인)
  - 자격요건: 건설사업관리기술자
- 책임감리원 (자격: 책임감리원 또는 감리단장): ____________ (인)
  - 자격요건: 건설사업관리기술자 (특급) + 책임감리원 교육 이수

- 일반사항은 본 문서의 검측결과란에 기재 후 통보로 갈음
