# 검측 체크리스트 — 철근공사 (배근 검측) — 발행기관: 국토교통부 / LH 품질관리지침 — 출처: https://www.molit.go.kr/LCMS/DWN.jsp (주요 공사별 점검 체크리스트), https://pumjil.lh.or.kr/nanum/site/builder/dir/main/img/menu5899/LH%ED%92%88%EC%A7%88%EA%B4%80%EB%A6%AC%EC%A7%80%EC%B9%A8.pdf — 수집일: 2026-05-28

## 표준 머리행
- Code No: ____________
- 검측일자: ____________ (YYYY-MM-DD)
- 공사명: ____________
- 공종: 철근콘크리트공사
- 부위별 세부공종: 기초 / 기둥 / 보 / 슬래브 / 벽체 (체크)
- 위치: ____________ (층/구역)

[1. 일반정보]
- 현장명: ____________
- 시공사: ____________
- 자재 공급원: ____________
- 가공장 (현장가공 / 공장가공): 체크
- 작업기간: ____________

[2. 자재 검수 항목]
- 항목 2.1: 철근 KS 마크 및 등급 확인
  - 검사기준: KS D 3504, SD400/SD500/SD600
  - 입력 타입: 적합/부적합 + 등급 텍스트
  - 등급: ____________

- 항목 2.2: 철근 제원 (직경, 길이, 중량)
  - 검사기준: KS D 3504 허용 오차
  - 입력 타입: 측정값
  - 직경: D____, 길이: ____ m

- 항목 2.3: 시험성적서 확인 (인장강도, 항복강도, 연신율)
  - 검사기준: SD400 항복강도 ≥ 400 MPa
  - 입력 타입: 첨부 + 적합/부적합

- 항목 2.4: 철근 표면 상태 (녹, 변형, 부식)
  - 검사기준: 들뜬녹 없음, 부식 단면적 5% 이내
  - 입력 타입: 적합/부적합

[3. 배근 검측 항목]
- 항목 3.1: 철근 종류 및 직경 (설계도서)
  - 검사기준: 도면대로
  - 입력 타입: 적합/부적합

- 항목 3.2: 철근 수량 (주근, 늑근/스터럽, 띠철근)
  - 검사기준: 도면대로
  - 입력 타입: 수량 입력
  - 주근: ____ 본, 늑근: ____ 본

- 항목 3.3: 철근 간격 (주근 간격, 늑근 간격)
  - 검사기준: 설계도서 ±20mm (KDS 14 20 50)
  - 입력 타입: 측정값(mm)

- 항목 3.4: 피복두께
  - 검사기준: 기초 80mm, 기둥/보 40mm, 슬래브 20mm (또는 도면)
  - 입력 타입: 측정값(mm)
  - 측정값: ____________

- 항목 3.5: 정착길이 (인장철근, 압축철근)
  - 검사기준: KDS 14 20 52 (40db 등)
  - 입력 타입: 측정값(mm)

- 항목 3.6: 이음길이 및 이음 위치
  - 검사기준: KDS 14 20 52, 50% 이상 동일위치 이음 금지
  - 입력 타입: 측정값(mm) + 위치 확인

- 항목 3.7: 갈고리 (Hook) 형상 및 길이
  - 검사기준: 90°/135°/180° 표준갈고리
  - 입력 타입: 적합/부적합

- 항목 3.8: 결속선 결속 상태 (교점 50% 이상)
  - 검사기준: 결속선 #18 이상, 교차점 결속
  - 입력 타입: 적합/부적합

- 항목 3.9: 스페이서/굄 설치 (피복 유지)
  - 검사기준: 1㎡당 4개 이상
  - 입력 타입: 적합/부적합

- 항목 3.10: 매립물·관통슬리브 위치 (간섭 여부)
  - 입력 타입: 적합/부적합

- 항목 3.11: 가스압접/기계식 이음 시험 (해당 시)
  - 검사기준: 강도 KS D 0244, 시험성적서
  - 입력 타입: 첨부

[4. 시험성과 (첨부)]
- 철근 시험성적서 (Mill Sheet): 첨부
- 가공도(샵드로잉): 첨부
- 가스압접 시험성적서 (해당 시): 첨부

- 조치사항: ____________

- 감리원 (자격: 건설사업관리기술자): ____________ (인)
