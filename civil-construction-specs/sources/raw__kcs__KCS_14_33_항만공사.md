# KCS 14 33 항만공사 — 국가건설기준센터(kcsc.re.kr) / 해양수산부 항만공사 표준시방서 — 수집일: 2026-05-28

## 1. 적용 범위
KCS 14 33은 항만의 외곽시설(방파제, 호안, 방조제), 계류시설(안벽, 잔교, 돌핀, 부두), 임항교통시설, 항만 준설·매립 공사에 적용한다. 해양수산부 발주 항만공사 및 지방 항만·어항 공사에 준용하며, 항만 및 어항 설계기준·해설(2014, KDS 64)과 병행 적용한다.

## 2. 재료 기준

### 2.1 콘크리트 (해양 환경 노출 기준)

| 부위 | 노출 등급 | 설계기준강도 | 물-결합재비 | 최소 시멘트량 | 최소 피복두께 |
|------|----------|------------|------------|-------------|-------------|
| 해수 수면 하 (침지부) | XS2 | 30 MPa | ≤ 0.45 | 360 kg/m³ | 60 mm |
| 해수 간만대 (조차부) | XS3 | 35 MPa | ≤ 0.40 | 380 kg/m³ | 70 mm |
| 해수 비말대 | XS3 | 35 MPa | ≤ 0.40 | 380 kg/m³ | 70 mm |
| 해상 대기 노출부 | XS1 | 24 MPa | ≤ 0.50 | 320 kg/m³ | 50 mm |

- 해양 환경 내구성 : 콘크리트 염화물 확산계수 D ≤ 1.0 × 10⁻¹² m²/s (방파제 케이슨)
- 혼화재 : 고로 슬래그 미분말(30~60 %) 또는 플라이애시(20~40 %) 복합 사용 권장 (내황산염성 향상)
- 공기량 : 3.5~6.0 % (해양 환경 동결융해 대비)

| 부재 | 강종 | 방식 처리 | 비고 |

| 강관 파일 (해수 중) | STK490, SKK490 | 에폭시 도장 + 전기방식 | KS D 3566 |

### 2.3 피복석 및 사석

| 항목 | 기준값 |
|------|--------|

| 흡수율 | ≤ 3.0 % |
| 점하중강도지수 (Is₅₀) | ≥ 3.5 MPa |
| 일축압축강도 | ≥ 40 MPa |
| 마모감량 | ≤ 35 % (로스앤젤레스 마모시험) |

## 3. 방파제 시공

### 3.1 경사식 방파제 (사석·블록식)

#### 피복재 설계
- 피복석 무게 : Hudson 공식 M = ρᵣ × H³ / (KD × (Sr-1)³ × cot α) 적용
  - Sr (비중) ≥ 2.6
  - KD : 사석=2.0, 테트라포드=7.0, 폭 0.6 이상
- 필터층 : 피복층 재료 무게의 1/10 ~ 1/20
- 사석기초 : 원지반 또는 굴착 정리면에 직접 포설, 두께 ≥ 1.0 m

#### 시공 허용 오차
| 항목 | 허용 오차 |
|------|---------|
| 제체 마루 높이 | ± 200 mm |
| 제체 폭 | 설계치 -0 ~ +500 mm |
| 피복재 거치 위치 | ± 300 mm |
| 수중 기초 마루 높이 | ± 300 mm |

### 3.2 직립식 방파제 (케이슨식)

#### 케이슨 제작 기준
- 콘크리트 타설 : 1 패널 연속 타설, 이음 없이 완성
- 케이슨 양생 : 탈형 후 최소 28일 수중 양생 (또는 7일 이상 습윤 양생 후 14일 이상 대기 양생)
- 방수 도막 : 외부 노출면 에폭시 도막 ≥ 200 μm

#### 케이슨 거치
- 거치 위치 오차 : 수평 ± 200 mm, 방위각 ± 0.5°
- 경사 : 수직도 1/200 이하
- 케이슨 간 틈새 : 10~50 mm (신축 허용)
- 속채움 : 사석 + 콘크리트 뚜껑 (상부 1.5 m)
- 기초 사석 고르기 : 마루 높이 오차 ± 50 mm (잠수 측량 확인)

## 4. 안벽(岸壁) 시공

### 4.1 중력식 안벽

| 항목 | 기준값 |
|------|--------|
| 콘크리트 설계기준강도 | ≥ 24 MPa (상치 콘크리트 30 MPa) |
| 기초 수평도 | ± 30 mm |
| 전면 수직도 | 1/200 이하 |
| 전면 직선도 | 10 m당 ± 30 mm |
| 마루 높이 | 설계치 ± 30 mm |

- 뒤채움 : 양질 사석 또는 쇄석, 다짐도 ≥ 90 %
- 배수 필터 : 부직포 + 사석 필터, 공극률 ≥ 35 %

### 4.2 잔교(棧橋) 및 돌핀

#### 강관 파일 시공
| 항목 | 기준값 |
|------|--------|
| 파일 수직도 | 1/100 이하 |
| 두부 위치 오차 | 수평 ± 50 mm |
| 경사 파일 경사도 오차 | ± 1/200 |
| 파일 두부 레벨 | 설계치 ± 20 mm |

- 파일 근입 깊이 : 설계 지지력 확인 후 결정, 정재하시험 또는 동재하시험 실시
- 파일 두부 처리 : 파일 내부 콘크리트 충전 (수면 위 3.0 m 이상 구간)

#### 상판 콘크리트
- 설계기준강도 : 35 MPa 이상 (해양 환경 XS3)
- 슬럼프 : 120~180 mm
- 타설 구획 : 1구획 면적 ≤ 150 m²
- 양생 : 습윤 양생 7일 이상 + 큐어링 컴파운드 도포

## 5. 항만 준설 및 매립

### 5.1 준설 기준

| 항목 | 기준값 |
|------|--------|
| 준설 심도 오차 | +0.5 m / -0.3 m |
| 수평 위치 오차 | ± 1.0 m |
| 암반 준설 허용 잔류 | +0.3 m |
| 검측 빈도 | 1,000 m²마다 측심 측량 1회 이상 |

- 준설토 투기 : 지정 투기장 외 투기 금지, 오탁 방지막 설치
- 오탁 기준 : 투기장 외부 방류수 SS ≤ 100 mg/L
- 준설 장비 : 그랩 준설선 (세립질), 커터 흡입 준설선 (사질), 착암기선 (암반)

### 5.2 매립

| 항목 | 기준값 |
|------|--------|
| 매립 후 다짐도 | ≥ 85 % (상대밀도 Dr ≥ 70 %) |
| 매립 표면 레벨 | 설계치 ± 0.3 m |
| 치환 모래 세립분 | 15 % 이하 |

- 연약지반 매립 : 압밀 촉진 공법(PBD, SCP) 병행 시 설계 목표 강도 cu ≥ 30 kPa 이상
- 지반 개량 완료 판정 : 압밀도 ≥ 90 % 또는 침하 수렴 확인

## 6. 방식 (防蝕) 공사

### 6.1 전기방식 시스템

| 항목 | 기준값 |
|------|--------|
| 방식 전위 (steel) | -0.80 V 이하 vs CSE (Ag/AgCl) |
| 음극 방식 전류 밀도 | 10~40 mA/m² (해수 침지부) |
| 희생 양극 교체 주기 | 설계 수명 20~30년 기준 |

- 전기방식 설치 후 방식 전위 측정 : 설치 후 3개월, 이후 연 1회
- 도장 방식 : 선행 표면 처리 Sa 2.5 이상 (ISO 8501-1), 도막 두께 매 도포 층 확인

### 6.2 콘크리트 방식

- 철근 콘크리트 : 에폭시 코팅 철근 또는 내식성 스테인리스 철근 사용 (조차부 이상)
- 표면 함침제 : 실란 계열, 흡수율 저감 ≥ 75 % (KCI-CT102)
- 양극화 보호 : 티타늄 메시 양극 + 임모탈라이제이션 시스템 (기존 구조물 보수)

## 7. 환경 및 시공 한계 조건

### 7.1 해상 작업 중지 기준

| 조건 | 중지 기준 |
|------|----------|
| 파고 (일반 작업) | 유의파고(Hs) ≥ 1.0 m |
| 파고 (케이슨 거치) | Hs ≥ 0.5 m |
| 풍속 | 10분 평균풍속 ≥ 10 m/s |
| 시정 | ≤ 200 m (수중 잠수 작업 중지) |
| 조류 유속 | ≥ 1.5 m/s (잠수 작업 중지) |

### 7.2 콘크리트 타설 환경 한계
- 한중 콘크리트 : 일 평균기온 ≤ 4°C
- 서중 콘크리트 : 일 최고기온 ≥ 35°C
- 해상 타설 시 : 풍속 ≥ 7 m/s, 파도 비말 주의 (피복 염화물 오염 방지)

## 8. 검측 단계 (Hold Point)

| 단계 | 검측 항목 |
|------|----------|
| 기초 준설·정지 완료 | 수심 측량, 위치 확인 |
| 기초 사석 포설 완료 | 마루 높이 측량 (잠수 측량 또는 멀티빔) |
| 케이슨 거치 | 위치·경사·높이 확인 |
| 케이슨 속채움 | 재료 품질, 다짐 확인 |
| 상치 콘크리트 전 | 철근 배근, 거푸집 확인 |
| 상치 콘크리트 완료 | 강도 (7일, 28일), 마루 높이, 균열 여부 |
| 파일 항타 완료 | 지지력 확인, 수직도 측정 |
| 매립 완료 | 레벨 측량, 다짐도 |
