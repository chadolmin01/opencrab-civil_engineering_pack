# KCS 12 지반조사 — 국가건설기준센터(kcsc.re.kr) — 수집일: 2026-05-28

## 1. 적용 범위
KCS 12는 건설공사 착수 전 지반의 공학적 특성을 파악하기 위한 현장 및 실내시험 전반에 적용한다. 보링, 샘플링, 원위치 시험, 실내 토질시험, 지하수 조사가 포함된다.

---

## 2. 조사 계획 및 간격 기준

### 2.1 보링 간격 기준

| 공사 종류 | 최대 보링 간격 | 최소 보링 수 |
|-----------|--------------|-------------|
| 도로·철도 노선 | 100~200 m | 노선당 3공 이상 |
| 교량 기초 | 교각 위치별 1~2공 | 교량당 3공 이상 |
| 터널 (NATM) | 갱구부 2공 + 50 m마다 1공 | 노선당 5공 이상 |
| 건축 기초 | 건물 모퉁이 + 중앙 | 500 m²당 1공 이상 |
| 옹벽·사면 | 10~30 m | 구조물당 3공 이상 |
| 연약지반 | 50~100 m | 단면당 3공 이상 |

### 2.2 보링 깊이 기준
- 구조물 최하단 기준 깊이 = **기초폭(B)의 3배 이상**, 최소 5 m
- 암반 확인 : 신선암 2 m 이상 관입 후 종료
- 연약지반 : 압밀 층 전체 관통 필수

## 3. 현장 시험

### 3.1 표준관입시험 (SPT)

| 항목 | 기준 |
|------|------|
| 해머 무게 | 63.5 kg |
| 낙하 높이 | 760 mm |
| 예비타 | 150 mm |
| 본타 | 300 mm 관입에 필요한 타격수 N값 기록 |
| N=0 처리 | 60타 이내 300 mm 미달 시 타격수/관입량 기록 |
| 보정 | 에너지 효율 보정(ER = 60 % 기준), 상재압 보정 적용 |

- N값 판정 기준 : 모래 N ≥ 30 (견고), 점토 N ≥ 15 (경질)
- 시험 간격 : 1.5 m 또는 지층 변화점

### 3.2 콘관입시험 (CPT / CPTU)

| 항목 | 기준값 |
|------|--------|
| 콘 저항 qc | 0.3 MPa 이하 → 연약지반 |
| 관입 속도 | 20 mm/s ± 5 mm/s |
| 측정 간격 | 20 mm 이하 연속 측정 |
| 과잉공극수압 u₂ | 소산시험 병행 (t₅₀ 측정) |
| 마찰비 Rf | 1 % 이하 → 모래, 3 % 이상 → 점토 판정 |

### 3.3 현장 베인시험 (FVT)
- 적용 조건 : 불교란 점토 cu ≤ 50 kPa
- 회전 속도 : 0.1 °/s
- 보정 계수 μ : Bjerrum 보정 μ = 1.0 (PI=30 %) ~ 0.55 (PI=100 %)
- 시험 위치 간격 : 깊이 방향 1.0 m 이상

### 3.4 평판재하시험 (PLT)
- 재하판 직경 : 300 mm 또는 750 mm
- 최대 하중 : 설계 허용지지력의 3배 또는 침하 25 mm 중 먼저 도달하는 값
- 하중 단계 : 최대 하중의 1/5씩 5단계 재하
- 침하 안정 기준 : 1분당 0.02 mm 이하

## 4. 샘플링 품질 등급

| 등급 | 교란도 | 채취 방법 | 활용 용도 |
|------|--------|----------|----------|
| Q1 | 불교란 | 고정 피스톤 샘플러, 포일 샘플러 | 압밀·삼축 시험 |

| Q4 | 교란 | 배럴 샘플러 | 육안 관찰, 입도분석 |

## 5. 실내 토질시험

### 5.1 필수 시험 항목

| 시험 | 기준 규격 | 시험 목적 |
|------|----------|----------|
| 함수비 | KS F 2306 | 기본 물성 |
| 단위중량 | KS F 2308 | 토압 계산 |
| 입도분석 | KS F 2309 | 흙 분류 |
| 액·소성한계 | KS F 2303, 2304 | 소성지수 |
| 비중 | KS F 2307 | 포화도 계산 |
| 표준 다짐 | KS F 2312 | OMC, γd,max |
| 일축압축 | KS F 2314 | 비배수전단강도 |
| 압밀 | KS F 2316 | 압축지수, cv |
| CU 삼축압축 | KS F 2346 | c', φ' |

### 5.2 시험 빈도 기준
- 층별 최소 3개 시료 (동일 지층 두께 3 m 이상 시 추가)
- 압밀 시험 : 연약층 두께 5 m마다 1회

---

## 6. 지하수 조사

### 6.1 지하수위 측정
- 보링 완료 후 24시간 경과 후 측정 (사질토)
- 점토 지반 : 72시간 이상 경과 후 측정
- 장기 계측 : 자동 수위계(Data Logger) 설치, 1일 2회 이상 기록

### 6.2 수질 분석 항목
- 황산이온(SO₄²⁻) : 600 mg/L 초과 시 내황산염 시멘트 사용 검토
- pH : 6.5 미만 시 콘크리트 부식 주의
- 염화물이온(Cl⁻) : 1,000 mg/L 초과 시 철근 부식 주의

---

## 7. 검측 단계

| 단계 | 검측 내용 | 허용 기준 |
|------|----------|----------|
| 보링 완료 | 깊이 확인, 코어 사진 | 설계 심도 ± 0.1 m |
| SPT 시행 | 해머 낙하 높이, 에너지 효율 | ER = 60 ± 5 % |
| 샘플링 | 채취율(RQD), 교란 여부 육안 확인 | 코어 채취율 ≥ 75 % (TCR) |
| 암반 분류 | RMR, Q값 산정 | 감독자 입회 |
| 실내시험 | 성과표 검토 | 반복 시험 ≤ 10 % 편차 |

## 8. 성과 보고서 필수 기재 항목

1. 지층 단면도 (보링 주상도)
2. N값 분포도
3. 지하수위 변동 이력
4. 흙의 분류표 (USCS)
5. 압밀·전단 정수 요약표
6. 지반 설계정수 추천값 (γ, c, φ, Es, mv, cv)
