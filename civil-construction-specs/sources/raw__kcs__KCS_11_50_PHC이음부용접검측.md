# KCS 11 50 PHC 파일 이음부 용접 검측 기준 — 출처: KCS 11 50 (국토교통부 건설기준) / KS F 4306 / KS B 0896 기반 — 수집일: 2026-05-28

## 개요

PHC(Pretensioned High-strength Concrete) 파일 이음부 용접은 교량 기초·건축 기초·항만 접안 시설 등의 말뚝 관입 시 파일 연장이 필요한 경우 적용하는 공정이다. 이음부 용접 품질 불량은 항타 충격 및 구조 하중에 의해 이음부 파단으로 이어질 수 있으며, 용접 전 개선(groove) 준비·예열·용접 비드 외관·초음파탐상(UT) 합격 여부가 핵심 검측 항목이다.

---

## 정량 기준

### 이음부 용접 사양

| 항목 | 기준값 |
|---|---|
| 용접봉 규격 | E4316 (저수소계) 또는 E4913 (KS D 7004 기준) |
| 개선 각도 | 단면 V형 개선 **60° ± 5°** |
| 루트 간격(Root Gap) | **0 ~ 3 mm** |
| 개선 면 거칠기 | 50 μm 이하 (그라인딩 후 확인) |

### 예열 및 층간 온도

| 항목 | 기준값 |
|---|---|
| 예열 온도 (외기 0 ~ 5 ℃) | **50 ℃ 이상** |
| 예열 온도 (외기 < 0 ℃) | **75 ℃ 이상** |
| 층간 온도 최대 한계 | **250 ℃ 이하** |
| 예열 범위 | 용접부 중심에서 **75 mm 이상** 사방 |

### 비드 외관 기준

| 검사 항목 | 합격 기준 |
|---|---|
| 언더컷(Undercut) 깊이 | **0.5 mm 이하** |
| 오버랩(Overlap) | **없음** |
| 크레이터(Crater) | 완전 충전, 균열 없음 |
| 표면 기공(Surface Porosity) | **직경 1.6 mm 이하** × **3개 이하/100 mm** |
| 용접 비드 높이 (여성 높이) | **1.5 ~ 3.0 mm** |
| 비드 폭 편차 | ± 2 mm 이내 |

### 초음파탐상(UT) 허용 결함 기준

| 결함 종류 | 허용 기준 |
|---|---|
| 균열(Crack) | **불허** (어떠한 크기도 불합격) |
| 융합 불량(Lack of Fusion) | **불허** |
| 기공(Porosity) | 결함 지시 길이 **6 mm 이하**이며 결함 면적 비율 **2 % 이하** |
| 슬래그 개재물 | 지시 길이 **6 mm 이하**, 간격 **50 mm 이상** |

## 검사·시험 방법

### 검측 절차

1. **용접 전 검측**
   - 개선 형상 확인: 개선 각도·루트 간격 측정 (버니어캘리퍼스)
   - 이물질 제거: 개선면 녹·기름·수분·도료 제거 여부 확인
   - 예열 온도 측정: 접촉식 온도계(서모크래용·표면 온도계)로 확인

2. **용접 중 검측**
   - 용접사 자격 확인: KS B 0885 또는 KS B 0884 자격 보유자
   - 층간 온도 측정: 각 패스 전 **표면 온도계**로 측정, 250 ℃ 초과 시 냉각 대기
   - 패스 수 및 순서: 루트 패스 → 충전 패스 → 커버 패스 (최소 3패스)

3. **용접 후 외관 검사**
   - 슬래그 제거 후 전 용접부 육안 검사
   - 결함 부위 표시 후 재용접 또는 그라인딩 보수

4. **초음파탐상(UT) 검사**
   - 장비: A-scan UT (KS B 0896 준용)
   - 탐촉자 주파수: **2.0 ~ 5.0 MHz** (경사각 탐촉자 45° 또는 60°)
   - 검사 범위: 이음부 전체 용접 길이 100 % 검사
   - 기준 반사원: φ2 mm 평저 공이나 SDH(Side Drilled Hole) 기준

### 검측 빈도

| 구분 | 빈도 |
|---|---|
| 외관 검사 | **전수 검사** (이음부 100 %) |
| UT 검사 | 이음부 **10 % 이상** 표본 검사 (불합격 발생 시 전수 전환) |
| 예열 온도 측정 | 이음 1개소당 **1회 이상** |

## 합격 기준

| 검사 항목 | 합격 기준 |
|---|---|
| 외관 — 언더컷 | ≤ 0.5 mm |
| 외관 — 기공 | ≤ 직경 1.6 mm × 3개/100 mm |
| 외관 — 균열 | 없음 |
| UT — 균열·융합 불량 | 없음 (무조건 불합격) |
| UT — 기공·슬래그 | 지시 길이 ≤ 6 mm |
| 예열 온도 | 외기 0~5 ℃: ≥ 50 ℃ / 외기 < 0 ℃: ≥ 75 ℃ |
