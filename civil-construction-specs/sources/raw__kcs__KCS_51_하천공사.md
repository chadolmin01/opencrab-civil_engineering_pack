# KCS 51 하천공사 — 국가건설기준센터(kcsc.re.kr) / 한국수자원공사(K-water) 표준시방서 — 수집일: 2026-05-28

## 1. 적용 범위
KCS 51은 하천의 제방, 호안, 수제, 낙차공, 보(洑), 배수문, 여수로, 준설·매립 등 하천공사 전반에 적용한다. 하천법 기반 국가·지방하천 및 소하천 정비사업에 적용하며, K-water 발주 하천사업 표준시방서와 병행 적용한다.

## 2. 제방 시공 기준

### 2.1 성토 재료 기준

| 항목 | 기준값 | 시험방법 |
|------|--------|----------|
| 최대입경 | 150 mm 이하 | KS F 2309 |
| 0.075 mm 통과율 | 35 % 이하 (제체), 25 % 이하 (천단·사면) | KS F 2309 |
| 유기물 함유량 | 5 % 이하 | KS F 2103 |
| 소성지수(PI) | 6 이상 20 이하 (차수 코어 적용 시) | KS F 2304 |
| 수정 CBR | 3.0 % 이상 | KS F 2320 |

### 2.2 제방 다짐 기준

| 위치 | 최소 다짐도 | 1회 포설 두께 | 다짐 후 두께 |
|------|------------|-------------|-------------|
| 제체 하부 (노체) | 90 % 이상 | 400 mm 이하 | 300 mm 이하 |
| 제체 상부 (노상) | 93 % 이상 | 300 mm 이하 | 200 mm 이하 |
| 천단부·법면 근접부 | 95 % 이상 | 200 mm 이하 | 150 mm 이하 |
| 구조물 뒤채움 | 95 % 이상 | 150 mm 이하 | 100 mm 이하 |

- 다짐 기준 : 수정 프록터 최대건조밀도(KS F 2312 D법)
- 검측 빈도 : 포설 면적 500 m² 또는 높이 1.0 m마다 1회 이상

### 2.3 제방 여유고 및 안전율

| 계획홍수량 (m³/s) | 여유고 |
|-----------------|--------|
| < 200 | 0.6 m |
| 200 ~ 500 | 0.8 m |
| 500 ~ 2,000 | 1.0 m |
| 2,000 ~ 5,000 | 1.2 m |
| ≥ 5,000 | 1.5 m |

- 제방 침투 안전율 : 비탈면 활동 Fs ≥ 1.3 (정상 상태), Fs ≥ 1.1 (급격한 수위 하강)
- 침투 압력 검토 : 제방 기초지반 수두비(i) ≤ 허용 동수경사

## 3. 호안 시공 기준

### 3.1 호안 공종별 적용 기준

| 공종 | 적용 유속 | 적용 조건 |
|------|----------|----------|
| 사석 호안 | ≤ 3.0 m/s | 직선부, 완경사 |
| 콘크리트 블록 호안 | ≤ 5.0 m/s | 직선부, 급경사 |
| 돌붙임·돌쌓기 | ≤ 4.0 m/s | 만곡부, 교량 교각 주변 |
| 식생 매트 | ≤ 2.0 m/s | 완경사, 녹화 구간 |
| 침상(沈床) 공 | ≤ 4.0 m/s | 하상 세굴 방지 구간 |

### 3.2 사석 호안

- 사석 단위중량 : 2,500 kg/m³ 이상
- 사석 직경 : 설계 유속에 따라 D = (V²/Cd×g×(Ss-1))^0.5 공식으로 산정, 최소 200 mm
- 사석 최소 두께 : 사석 직경의 2배 이상
- 시공 수직도 : 설계 경사 ± 3° 이내

### 3.3 돌쌓기 호안

- 찰쌓기 : 줄눈 모르타르 1:3 (시멘트:모래), 두께 20~30 mm
- 메쌓기 : 배수공 설치 간격 ≤ 3.0 m
- 기초 근입 깊이 : 하상 최심부 이하 1.0 m 이상, 최소 0.5 m

## 4. 수제(水制) 시공

### 4.1 수제 기본 규격

| 항목 | 기준 |
|------|------|
| 수제 길이 | 저수로 폭의 1/10 ~ 1/4 |
| 수제 간격 | 수제 길이의 1.5 ~ 2.0배 |
| 수제 높이 | 계획홍수위 이하 |
| 수제 경사 (평면) | 흐름 방향 기준 상류 측 60~75° |

### 4.2 수제 재료 선정
- 단통형 수제 : 사석 평균입경 ≥ 300 mm
- 말뚝형 수제 : 강관파일 φ300 이상, 근입 깊이 하상 이하 2.0 m 이상
- 방틀형 수제 : 목재 방틀 + 내부 사석 채움, 방틀 강결합

## 5. 보(洑) 및 낙차공

### 5.1 보 시공

| 항목 | 기준값 |
|------|--------|
| 콘크리트 설계기준강도 | 21 MPa 이상 (물 접촉부 24 MPa) |
| 물-시멘트비 | ≤ 0.55 |
| 최소 피복두께 | 60 mm (수중), 40 mm (지상) |
| 양생 기간 | 습윤 양생 7일 이상 (보통 시멘트), 5일 이상 (조강 시멘트) |

- 세굴방지공 : 하류 물받이+바닥막이 설치, 세굴깊이 = 1.5~2.0 × 낙차
- 물받이 콘크리트 두께 : 300 mm 이상
- 하류 바닥막이 길이 : 낙차의 3배 이상

### 5.2 어도(魚道) 시공
- 어도 경사 : 1/10 이하
- 격벽 간격 : 2.0~4.0 m
- 유속 : 0.6~1.2 m/s (어종별 상이)
- 수심 : 평수기 기준 0.2 m 이상

## 6. 준설 및 매립

### 6.1 준설 기준

| 항목 | 기준 |
|------|------|
| 준설 허용 오차 (심도) | 설계 심도 +0.3 m, -0.1 m |
| 수평 위치 오차 | ± 0.5 m 이내 |
| 준설 검측 빈도 | 500 m² 이하마다 측심 측량 |

- 준설토 운반 : 수계 오염 방지, 부유물질 관리 (SS ≤ 50 mg/L 방류 기준)
- 암 준설 : 발파 전 진동 측정, 인접 구조물 허용 진동속도 ≤ 2.0 cm/s

### 6.2 매립 성토
- 세립질 재료(세사·실트) : 층두께 150~200 mm, 진동 다짐
- 침하 고려 : 매립 완료 후 6개월 이상 압밀 침하 계측

---

## 7. 환경 및 시공 한계 조건

### 7.1 작업 중지 기준

| 조건 | 중지 기준 |
|------|----------|
| 강우 | 시간 강우 10 mm/h 이상 시 성토·다짐 중지 |
| 기온 (콘크리트 타설) | 일 평균기온 4°C 이하 → 한중 콘크리트 적용 (KCS 14 20 11) |
| 기온 (콘크리트 타설) | 일 최고기온 35°C 이상 → 서중 콘크리트 적용 |
| 홍수 경보 | 홍수 예보 발령 시 전 작업 중지, 장비 철수 |
| 하천 유속 | 유속 ≥ 2.0 m/s 시 수중 작업 중지 |

### 7.2 홍수기 시공 제한
- 홍수기(6.21~9.20) : 제방 성토·다짐 기준 강화, 법면 보호 필수
- 홍수기 중 가물막이 설치 제한 : 소통 단면 50 % 이상 확보 의무
- 공사 잔재물·장비 : 홍수 예보 6시간 내 철거 완료

## 8. 계측 및 품질관리

### 8.1 제방 침하·변위 계측

| 계측 항목 | 설치 간격 | 계측 빈도 |
|----------|---------|----------|
| 지중 침하계 | 200~300 m | 성토 중 1회/일, 완료 후 1회/주 |
| 공극수압계 | 200~300 m | 성토 중 1회/일, 완료 후 1회/주 |
| 경사계 | 200~300 m | 1회/주 |
| 표면 침하 측점 | 50~100 m | 1회/주 |

- 성토 속도 : 공극수압 과잉 발생 시 성토 속도 조절 (일 성토 높이 ≤ 0.3 m/day — 연약지반)

### 8.2 검측 단계 (Hold Point)

| 단계 | 검측 항목 |
|------|----------|
| 기초지반 확인 | 지지력 확인, 연약 범위 파악 |
| 성토 50 % 완료 | 다짐도, 침하 측량 |
| 성토 완료 | 다짐도, 높이·폭 측량, 법면 경사 확인 |
| 호안 기초 완료 | 근입 심도, 지지력 확인 |
| 호안 본체 완료 | 줄눈·단면·경사 확인, 결함 여부 |
| 구조물 콘크리트 타설 전 | 거푸집·철근 배근 확인 |
| 구조물 콘크리트 양생 완료 | 강도 시험 (7일, 28일) |

## 9. 주요 정량 기준 요약

| 기준 항목 | 정량값 |
|----------|--------|
| 제체 다짐도 (하부) | ≥ 90 % (수정 프록터) |
| 제체 다짐도 (상부) | ≥ 93 % |

| 세굴방지 바닥막이 길이 | 낙차 × 3 이상 |
| 준설 심도 허용 오차 | +0.3 m / -0.1 m |

| 연약지반 성토 속도 | ≤ 0.3 m/day |
| 하천 수중 작업 중지 유속 | ≥ 2.0 m/s |

| 사석 호안 적용 유속 한계 | ≤ 3.0 m/s |
