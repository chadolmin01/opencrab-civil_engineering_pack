# KS F 2526 — 콘크리트용 골재 (Aggregates for concrete) — 출처: domain knowledge — verified against KDS/KCS citations — 수집일: 2026-05-28

[적용 범위]
콘크리트에 사용하는 잔골재 및 굵은 골재(천연·인공)의 품질을 규정한다.

[잔골재 (fine aggregate) 품질 — 일반]
- 입경 : 5 mm 체 95 % 이상 통과
- 절대건조밀도 : 2.5 g/cm³ 이상
- 흡수율 : 3.0 % 이하
- 안정성 (황산나트륨) : 10 % 이하
- 0.08 mm 체 통과량 : 3.0 % 이하 (콘크리트), 5.0 % 이하 (모르타르)
- 점토 덩어리 : 1.0 % 이하
- 유기 불순물 : 표준색 이하
- 염화물 (NaCl 환산) : 0.04 % 이하

[잔골재 입도]
조립률(F.M.) 2.3 ~ 3.1 권장

[굵은 골재 (coarse aggregate) 품질 — 일반]
- 최대치수 : 부재 최소치수의 1/5, 철근 최소 간격의 3/4, 슬래브 두께의 1/3 이하
- 절대건조밀도 : 2.5 g/cm³ 이상
- 흡수율 : 3.0 % 이하
- 안정성 (황산나트륨) : 12 % 이하
- 마모율 (로스앤젤레스) : 40 % 이하 (포장용 25 % 이하)
- 0.08 mm 체 통과량 : 1.0 % 이하
- 점토 덩어리 : 0.25 % 이하
- 연약한 알갱이 : 5.0 % 이하

[굵은 골재 표준 입도 (최대치수 25 mm)]
- 25 mm 체 통과 : 90 ~ 100 %
- 19 mm 체 통과 : 20 ~ 55 %
- 10 mm 체 통과 : 0 ~ 10 %
- 5 mm 체 통과 : 0 ~ 5 %

[단위용적질량 시험 (참조)]
KS F 2505. 잔골재 1.45 t/m³ 이상, 굵은 골재 1.50 t/m³ 이상.

[알칼리-실리카 반응성]
화학법(KS F 2545) 또는 모르타르봉법(KS F 2546)으로 무해(innocuous) 판정 필요.

[참조]
KS F 2502 골재 체가름 시험, KS F 2503 골재 밀도·흡수율 시험, KS F 2508 마모 시험.
