# KS B 0801 — 금속재료 인장 시험편 (Test pieces for tensile test for metallic materials) — 출처: domain knowledge — verified against KDS/KCS citations — 수집일: 2026-05-28

[적용 범위]
KS B 0802의 인장 시험 방법에 사용하는 금속 시험편의 형상·치수·표시 방법.

[비례 시험편 — 게이지 길이]
- 일반 : Lo = 5.65 √Ao (Ao = 단면적, mm²) → 원형 단면 Lo = 5d
- 장형 : Lo = 11.3 √Ao → 원형 단면 Lo = 10d
- 결과는 시험편 형상 무관하게 비교 가능

[비례 시험편 — 표준 치수 (원형 단면)]
- 평행부 지름 d : 14, 12.5, 10, 8, 6, 5, 4, 3, 2.5 mm 등
- 평행부 길이 Lc : Lo + d ~ Lo + 2d (또는 Lo + d/2 이상)
- 그립부 지름 D : d × 1.4 이상
- 어깨부 곡률 반지름 R : d 이상

[판상 시험편 (1A·1B호) — 두께 0.5 ~ 25 mm]
- 표점 폭 b : 25 mm (1A호), 12.5 mm (1B호)
- 표점 거리 Lo : 50 mm (1A호), 25 mm (1B호)
- 평행부 길이 Lc : Lo + 2b
- 어깨부 곡률 반지름 R : 20 mm 이상

[2호·3호·4호 시험편 (구·신 호칭)]
- 2호 : 표점 50 mm, 폭 25 mm, 두께 원판
- 4호 : 표점 50 mm, 폭 25 mm (평행부 60 mm 이상)
- 5호 : 봉강·이형철근용. 표점 5d, 평행부 5.5d ~ 6d 이상

[14호 시험편 — 이형철근용]
- 표점 거리 : 호칭 지름의 5배 (5d)
- 평행부 : 호칭 지름의 5.5d 이상
- 단면적 : 호칭 단면적 사용

[표면 가공]
- 비례 시험편 : 표면 거칠기 Ra 3.2 μm 이하 권장
- 평행부 직각도 0.05 mm 이하
- 시험편에 노치(notch)·결함 금지

[표시]
시험편에 식별 번호, 채취 위치(LT/LP/TT 방향) 표시.

[참조]
KS B 0802 인장 시험 방법, KS D 3504 철근 봉강, KS D 3503 일반 구조용 강재.
