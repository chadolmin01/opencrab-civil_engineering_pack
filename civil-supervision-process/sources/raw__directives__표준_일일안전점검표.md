# 건설현장 일일 안전점검표 표준 — 국토교통부 · 고용노동부(산업안전보건공단) — 출처: 「건설공사 안전관리 업무수행지침」, 「산업안전보건법」 시행규칙, KOSHA Guide C-104 · domain knowledge fallback — 수집일: 2026-05-28

## 1. 적용 범위
- 모든 건설공사(공공·민간) 의무
- 작업 착수 전(TBM: Tool Box Meeting) 매일 1회 + 위험작업 수시
- 「건설기술 진흥법」 제62조 + 「산업안전보건법」 제29·64조

## 2. 점검 시점 정량
- **작업 전 점검(TBM)**: 매일 08:00 이전, 10~15분
- **순회 점검**: 작업 중 오전 1회 + 오후 1회 (안전관리자 직접)
- **위험작업 별도 점검**: 굴착·고소·중량물·발파·화기 작업 30분 전·후
- **작업 종료 점검**: 매일 17:00 이후, 익일 안전조치 확인

## 3. 점검 체크 항목 (표준 8대 분야)
1. **개인보호구**: 안전모·안전화·안전대·보안경·마스크 착용 (100% 미착용 시 작업 중지)
2. **위험성평가**: 당일 작업 위험요인 식별·대책 게시
3. **가설구조물**: 비계·작업발판·안전난간·승강설비 점검
4. **굴착·흙막이**: 토류벽 변위·지하수위·균열 (1일 1회 측정)
5. **고소작업**: 추락방호망·안전대 부착설비·작업발판 폭 40cm 이상
6. **중장비**: 운전자 자격(면허)·시야·후방경보·작업반경 출입통제
7. **전기·화기**: 누전차단기·접지·소화기·인화물 격리(5m 이상)
8. **밀폐공간**: 산소(18% 이상)·유해가스(LEL 10% 이하) 측정, 출입자 명단

## 4. 정량 측정 기준
| 항목 | 측정값 | 합격 기준 |
|---|---|---|
| 비계 수직도 | 측정 | 1/600 이내 |
| 작업발판 폭 | 측정 | 40cm 이상 (이격 3cm 이하) |
| 안전난간 높이 | 측정 | 90~120cm |
| 추락방호망 처짐 | 측정 | 단변길이 12% 이하 |
| 토류벽 변위 | 인클리노미터 | 일변위 5mm/허용누적 변위 50mm |
| 지하수위 | 관측정 | 일 변동 ±300mm 이상 시 보고 |
| 소음 | 소음계 | 작업장 90dB 이하 |
| 진동 | 진동계 | 발파 진동속도 0.5cm/s 이하 (주거지 기준) |
| 분진 | 분진계 | 호흡성분진 5mg/㎥ 이하 |
| 산소 농도(밀폐) | 산소측정기 | 18~23.5% |
| 유해가스(밀폐) | 가스측정기 | 황화수소 10ppm 이하, CO 30ppm 이하 |

## 5. 서명 체인
- TBM 점검표: 작업반장 → 안전관리자 → 현장대리인 (매일)
- 위험작업 점검표: 작업지휘자 → 안전관리자 → 감리원(입회 서명) → 현장대리인
- 주간 종합 점검: 안전관리자 → 책임감리원 → 발주청 감독관

## 6. 부적합 시 조치
- 즉시 시정 가능: 작업 일시중지 → 시정 → 재개
- 중대 위험: 작업중지권 발동 (안전관리자·감리원·근로자 모두 가능)
- 산업안전보건법 제51조 작업중지 → 발주청·노동청 보고 의무
