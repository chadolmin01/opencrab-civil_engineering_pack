# 국가철도공단 건설사업관리(감리) 업무 세부지침 — 국가철도공단(KR) — 출처: 국가철도공단 공시 지침 (kr.or.kr 자료실) · domain knowledge fallback — 수집일: 2026-05-28

## 1. 적용 범위
- 고속철도·일반철도 신설·개량·전철화·복선화 공사
- 「철도건설법」 및 국가철도공단 「철도건설공사 감리업무 수행지침」
- 차량운행선 인접공사·궤도공사·전차선공사 포함 전 공사 대상

## 2. 감리원 배치 정량 기준
| 공종 | 책임감리원 | 분야 감리원 | 특수자격 |
|---|---|---|---|
| 토공·교량·터널 본선 | 1명(특급) | 토목·구조·지반 각 1명 | - |
| 궤도공사 | 1명(특급) | 궤도·재료 각 1명 | 궤도기능사·기사 |
| 전차선(전철화) | 1명(특급) | 전기·통신 각 1명 | 전기철도기술사·기사 |
| 신호·통신 | 1명(고급) | 신호·통신 각 1명 | 철도신호기사 |
| 노반 + 궤도 통합 1공구 | 책임감리원 1명 + 분야별 2명 이상 | 시속 250km 이상 노선: 특급 의무 |

- 영업선 인접공사: 안전관리감리원 별도 배치 (24시간 교대 가능 인력)

## 3. 핵심 절차 단계
1. **착수단계**
   - 영업선 인접공사 시 KORAIL과 협의(작업협의서) 우선
   - 차단작업계획서·열차감시원 배치계획 검토 → 공단 승인
2. **시공단계**
   - 토공·교량·터널: 도로공사 준용 + 철도하중 고려 (LM-22 / KRL-2012)
   - 궤도공사: 궤간·줄맞춤·면맞춤·수평·뒤틀림 정밀 측정
   - 전차선: 가선장력·편위·높이 측정, 절연이격 확인
3. **중지점(Hold Point)**
   - 토공/구조물: 도공 기준 준용
   - 궤도: 침목 설치 / 레일 부설 / 체결구 체결 / 도상 자갈 다짐 / 안정화 작업 / 정밀줄맞춤
   - 전차선: 전주 건립 / 가선 / 장력조정 / 절연저항 / 통전시험
4. **시운전 단계**
   - 정지시험 → 저속(40km/h) → 단계별 속도 향상 → 영업속도 확인시험
   - 감리원 입회·서명 의무

## 4. 서명 체인
- 차단작업 검측: 시공팀장 → 안전관리감리원 → 책임감리원 → 공단 감독관 → KORAIL 운영관리자
- 궤도 정밀측정: 측량반장 → 궤도감리원 → 책임감리원 → 공단 시설처
- 전차선 가선장력: 시공기사 → 전기감리원 → 책임감리원 → 공단 전기처
- 시운전 결과: 시운전반장 → 분야별 감리원 → 책임감리원 → 공단 건설본부장

## 5. 검측 빈도 정량 기준
- 노반 다짐도: KR 기준 1,000㎡당 5점 / 노반층 K30 ≥ 110 MN/㎥
- 도상자갈: 입도시험 500㎥당 1회, 마모율 25% 이하
- 레일 용접부 초음파탐상: 100% 검사 + 외관검사
- 궤도 정밀측정 허용오차:
  - 궤간: +3mm / -2mm (250km/h 이상: +2/-1mm)
  - 줄맞춤(통과기준): 10m 현 2mm 이내
  - 면맞춤: 10m 현 3mm 이내
  - 수평: 3mm 이내
- 전차선 높이: 5,200mm ±20mm (고속 5,080mm ±10mm)
- 전차선 편위: 좌우 200mm 이내 (지그재그)
- 절연저항: 1MΩ 이상 (1,000V 메거)
- 안전점검: 차단작업 시 작업 전·중·후 각 1회, 열차감시원 30분마다 보고

## 6. 공단 고유 추가 의무
- 철도시설관리정보시스템(KR-CMIS) 입력: 일일 1회
- 영업선 인접공사 안전점검 결과 KORAIL 통보: 매주
- 시운전 단계별 감리보고서 공단 본부 제출
- 철도하중 적용 구조계산 재검토 의무 (LM-22, KRL-2012, EL 활하중)
