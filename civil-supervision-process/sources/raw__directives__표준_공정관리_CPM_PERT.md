# 건설공사 공정관리 표준 (CPM·PERT 기반) — 국토교통부 · 한국건설기술연구원 — 출처: 「건설공사 공정관리지침」, KCS 10 10 10, CODIL · domain knowledge fallback — 수집일: 2026-05-28

## 1. 적용 범위
- 「건설기술 진흥법」 시행령 제87조: 공정관리 의무화
- 총공사비 100억원 이상: CPM 네트워크 기반 공정관리 의무
- 공기 12개월 이상 또는 동시 작업 20개 이상 공종: PERT 적용 권장

## 2. 핵심 개념 정의
- **CPM(Critical Path Method)**: 결정론적, 작업기간 1개 값 (확정 공기)
- **PERT(Program Evaluation and Review Technique)**: 확률론적, 낙관(O)·정상(M)·비관(P) 3점 추정
  - 기대시간 TE = (O + 4M + P) / 6
  - 분산 σ² = ((P − O) / 6)²
- **주공정(Critical Path)**: TF(Total Float) = 0인 경로, 공기 좌우
- **여유시간**:
  - TF(전체여유) = LS − ES = LF − EF
  - FF(자유여유) = 후속작업 ES − 당해작업 EF
  - DF(종속여유) = TF − FF

## 3. 표준 절차 단계
1. **작업분할(WBS)**: 공종을 작업단위로 분할 (최소 단위 1일)
2. **작업 간 선후관계 정의**: FS(Finish-to-Start) 원칙, 필요시 SS/FF/SF
3. **작업기간 산정**:
   - CPM: 표준 품셈·생산성 자료 + 자원 가용량
   - PERT: 3점 추정 후 TE 계산
4. **네트워크 작성**: ADM(화살선도) 또는 PDM(노드선도)
5. **일정 계산**: 전진계산(ES·EF) → 후진계산(LS·LF) → 여유 계산 → 주공정 도출
6. **자원평준화(Resource Leveling)**: 일일 최대 인원·장비 제약 반영
7. **공정관리 실행**:
   - 매주 진도 측정(Earned Value 기반)
   - 지연 시 단축 기법(Crashing·Fast Tracking) 검토

## 4. 진도 측정 정량 지표 (EVM)
- **PV(Planned Value)**: 계획 기성 누계
- **EV(Earned Value)**: 실제 달성한 작업의 계획기성
- **AC(Actual Cost)**: 실제 투입비
- **SV(일정차)** = EV − PV (음수 = 지연)
- **CV(비용차)** = EV − AC (음수 = 초과)
- **SPI(일정효율)** = EV / PV (1.0 미만 = 지연)
- **CPI(비용효율)** = EV / AC (1.0 미만 = 초과)

### 경보 임계값 (정량)
| 지표 | 정상 | 경고 | 위험 |
|---|---|---|---|
| SPI | ≥ 0.95 | 0.85~0.95 | < 0.85 |
| CPI | ≥ 0.95 | 0.85~0.95 | < 0.85 |
| 주공정 지연 | 0일 | 1~7일 | 7일 초과 |

## 5. 보고 주기
- 일일: 작업일보 + 진도율 입력
- 주간: 주간공정회의 (시공·감리·발주 3자), 다음 주 계획·전주 실적
- 월간: 월간공정보고서, 만회대책 포함
- 분기: 전체 공정 재검토 + CPM 갱신

## 6. 서명 체인
- 작업일보·주간보고: 현장기사 → 공무팀장 → 현장대리인 → 분야감리원 → 책임감리원
- 월간공정보고: 시공사 대표 → 책임감리원 → 발주청 감독관 → 사업단장
- 공정 변경(공기 5% 이상): 변경공정표 → 감리 검토의견 → 발주청 승인

## 7. 만회대책(지연 시) 정량
- 주공정 7일 이상 지연: 만회대책서 7일 이내 제출 의무
- 만회대책 수단:
  - 인원 증원 (당초 대비 130% 이내, 학습곡선 고려)
  - 작업시간 연장 (1일 12시간 이내, 산업안전보건법 준수)
  - 야간작업 (소음·민원 협의 후)
  - 공법 변경 (감리·발주 승인 필수)
  - Fast Tracking (병행작업) - 추가 리스크 평가 필수
