# 건설공사 시공계획서 표준 양식 — 국토교통부 · 조달청 — 출처: 「건설공사 시공관리 지침」, 조달청 표준시방서, KCS 10 10 05 · domain knowledge fallback — 수집일: 2026-05-28

## 1. 적용 범위
- 모든 건설공사: 착공 전 발주청 승인 의무 (「건설기술 진흥법」 제62조 시행규칙 제58조)
- 총괄 시공계획서: 착공 30일 이내
- 공종별 시공계획서: 해당 공종 착수 14일 전

## 2. 표준 목차 (11장 구성)

### 제1장 일반사항
- 공사 개요(공사명·발주처·계약일·공기·계약금액)
- 적용 법령·시방서·도면 목록
- 용어 정의

### 제2장 현장 조직
- 현장 조직도 (현장대리인 이하)
- 주요 인력 자격·경력 (현장대리인은 「건설기술 진흥법」 자격 기준)
- 협력업체 명단 및 면허·등록증

### 제3장 공사 일반
- 위치도·인접 시설 현황
- 지반·지질·기상 조건
- 가설 시설 배치도(사무실·자재창고·작업장)

### 제4장 공정계획
- 전체 공정표 (CPM 또는 PERT 네트워크)
- 월간·주간 공정 계획
- 마일스톤(주요 중지점) 일정
- 우기·동절기 대비 공정 조정

### 제5장 공종별 시공방법
- 공종별 시공 순서·방법·장비 투입 계획
- 시공 상세도(가설공법 포함)
- 핵심 공종: 토공·기초·골조·마감 등 분리 작성
- 신기술·신공법 적용 시 별도 검증자료

### 제6장 품질관리계획
- 품질관리조직 (품질관리자 자격)
- 자재별 시험계획·시험빈도(KS·KCS 기준)
- 시공검측 계획·중지점(Hold Point) 목록
- 부적합품 처리 절차

### 제7장 안전·환경 관리계획
- 위험성평가 (KOSHA Guide R-67 준용)
- 안전관리비 사용 계획
- 비상연락망·응급체계
- 환경관리: 소음·진동·분진·폐기물·수질

### 제8장 자재 조달 계획
- 주요 자재 수급 계획(반입 시기·수량·공급처)
- 자재 보관·운반·관리 계획
- 시험성적서 제출 계획

### 제9장 장비 운용 계획
- 주요 장비 투입 계획 (종류·규격·시기)
- 장비 점검·정비 계획

### 제10장 민원·교통 관리
- 인접 주민 협의·민원 대응
- 교통 관리 계획 (도로점용·우회로)

### 제11장 사진관리 계획
- 촬영 단계·빈도(국토부 사진촬영기준 준용)
- 사진대지 작성·제출 일정
- 매몰부 사진관리 절차

## 3. 첨부 의무 자료
- 공정표(CPM 네트워크 + 간트차트)
- 가설계획도·작업장 평면도
- 시공 상세도
- 위험성평가 결과서
- 품질관리계획서·안전관리계획서·환경관리계획서

## 4. 서명 체인
- 작성: 시공사 공무팀장 → 검토: 현장대리인 → 시공사 대표이사
- 검토: 분야별 감리원 → 책임감리원 (검토의견서 첨부)
- 승인: 발주청 공사감독관 → 발주청 사업단장
- 변경 시: 시공계획서 변경요청서 + 변경공정표 → 동일 서명 체인

## 5. 변경 기준
- 공기 5% 이상 또는 30일 이상 변동 시: 변경 시공계획서 의무 제출
- 시공방법·공법 변경 시: 사전 승인
- 협력업체 변경 시: 면허·등록 확인 후 통보

## 6. 정량 표준
- 공정표: 작업 단위 최소 1일, 핵심 공종은 시간 단위 가능
- 마일스톤 수: 공기 12개월당 최소 8개
- 시공계획서 분량: 총괄 100~200쪽 / 공종별 30~50쪽
- 갱신: 분기 1회 + 변경 발생 시 즉시
