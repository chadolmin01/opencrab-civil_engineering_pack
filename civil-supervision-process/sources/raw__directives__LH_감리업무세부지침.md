# LH 건설사업관리(감리) 업무 세부지침 — 한국토지주택공사(LH) — 출처: LH 공시 지침 (lh.or.kr 자료실) · domain knowledge fallback — 수집일: 2026-05-28

## 1. 적용 범위
- LH가 발주하는 공동주택, 단지조성, 상하수도, 도로, 택지개발 등 모든 건설공사
- 「건설기술 진흥법」 제39조 및 LH 자체 「건설사업관리 업무수행지침」 우선 적용
- 총공사비 200억원 이상: 책임감리(상주) 의무
- 총공사비 100억원 이상 ~ 200억원 미만: 부분 책임감리

## 2. 감리원 배치 정량 기준
| 공사 규모 | 책임감리원 | 분야별 감리원 | 상주 여부 |
|---|---|---|---|
| 500억원 이상 | 1명 (특급) | 토목·건축·기계·전기 각 1명 (고급 이상) | 상주 |
| 200~500억원 | 1명 (고급 이상) | 토목·건축 각 1명 | 상주 |
| 100~200억원 | 1명 (중급 이상) | 분야 통합 가능 | 부분 상주 (주 3일 이상) |
| 100억원 미만 | 1명 (중급) | 1명 | 비상주 (월 2회 이상 현장 점검) |

- 감리원 1인당 관리 면적: 공동주택 50,000㎡ / 단지조성 100,000㎡ 초과 시 추가 배치
- 동시 수행 가능 현장 수: 책임감리원 1개, 분야별 감리원 2개 이하

## 3. 핵심 절차 단계
1. **착수단계**
   - 감리원 배치계획서 제출 (착수 7일 전) → LH 사업단장 승인
   - 감리업무 수행계획서 제출 (착수 14일 이내)
   - 시공계획서 검토 및 승인 (착수 30일 이내)
2. **시공단계 일상 감리**
   - 매일: 시공일지 검토·서명, 안전점검 입회
   - 주간: 공정회의 주관 (시공사·발주처·감리 3자)
   - 월간: 기성검사, 자재반입 누계 보고, LH 사업단 보고
3. **검측(중지점, Hold Point)**
   - 시공사 검측요청서(48시간 전) → 감리원 입회 검측 → 합격/재시공 판정
   - 핵심 중지점: 터파기 완료 / 철근 배근 완료 / 거푸집 설치 완료 / 콘크리트 타설 직전 / 양생 완료 / 마감 직전
4. **준공단계**
   - 예비준공검사 (준공 14일 전) → 본준공검사 → LH 사용승인

## 4. 서명 체인
- 시공일지: 작업반장 → 현장대리인 → 분야별 감리원 → 책임감리원
- 검측체크리스트: 시공기사 → 현장대리인 → 품질관리자 → 감리원 → 책임감리원
- 자재반입검수: 자재담당자 → 품질관리자 → 감리원 → (시험성적서 첨부) 책임감리원
- 시공계획서·변경설계서: 시공사 대표 → 책임감리원 → LH 공사감독관 → LH 사업단장

## 5. 검측 빈도 정량 기준
- 콘크리트 압축강도시험: 150㎥당 1로트 (공시체 3개)
- 철근 인장시험: 종류·지름별 50톤당 1조 (3개 공시체)
- 토공 다짐도시험: 1,000㎡당 3점, 층(層)별 매 30cm
- 골재 입도시험: 반입 로트당 1회
- 거푸집 변위 측정: 타설 전·중·후 3회 (수직 1/300 이내, 수평 1/500 이내)
- 안전점검: 매일 작업 전 1회 + 위험작업 시 수시
- 사진촬영: 각 공종 착수·진행·완료 3단계 + 매몰부 추가

## 6. LH 고유 추가 의무
- LH 통합건설관리시스템(LH-CMS) 입력: 일일 1회 (당일 18시 전)
- 품질·안전 우수사례 보고: 분기 1회
- 하자담보책임 사전 점검: 준공 30일 전 별도 회의 개최
