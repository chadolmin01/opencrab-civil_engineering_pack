## 표준 머리행 (모든 검측 체크리스트 공통)
- Code No: ____________ (체크리스트 번호)
- 검측일자: ____________ (YYYY-MM-DD)
- 공사명: ____________
- 공종: 콘크리트공사
- 부위별 세부공종: 타설 전 준비 / 타설 중 / 타설 후 양생
- 위치: ____________ (구역, 부재명, 통선)
- 공사량: ____________ (m³)

[1. 일반정보]
- 현장명: ____________
- 시공사: ____________
- 감리단: ____________
- 타설일자: ____________
- 타설시간: ____________ (시작 ~ 종료)
- 기상: 맑음 / 흐림 / 비 / 눈 (체크박스)
- 기온: ____________ ℃
- 습도: ____________ %

[2. 타설 전 검측 항목]
- 항목 2.1: 거푸집 청소 및 정리 상태
  - 검사기준(시방): 이물질 제거, 박리제 도포 완료
  - 입력 타입: 적합/부적합 체크
  - 검사결과: ____________
  - 조치사항: ____________

- 항목 2.2: 거푸집 변형·간격·수직도
  - 검사기준: 허용오차 ±3mm, 수직도 1/500 이내
  - 입력 타입: 측정값(mm) + 적합/부적합
  - 검사결과: ____________

- 항목 2.3: 철근 배근 (간격, 피복두께, 정착길이, 이음길이)
  - 검사기준: 설계도서 및 KDS 14 20 50
  - 입력 타입: 측정값 + 적합/부적합
  - 검사결과: ____________

- 항목 2.4: 매립물(전기·기계 슬리브, 인서트) 위치
  - 검사기준: 설계도서대로 위치/수량
  - 입력 타입: 적합/부적합 체크

- 항목 2.5: 타설 장비 점검 (펌프카, 진동기 수량/예비, 슈트)
  - 입력 타입: 적합/부적합 체크
  - 진동기 수량: ____________ 대 (예비 포함)

- 항목 2.6: 레미콘 배합표 확인 (배합비, 호칭강도, 슬럼프, 공기량 설계값)
  - 검사기준: 설계기준강도 fck ≥ ____________ MPa
  - 입력 타입: 텍스트(배합표 첨부)

- 항목 2.7: 콘크리트 운반시간 (KS F 4009: 90분 이내, 25℃ 이상은 60분)
  - 입력 타입: 분 단위 숫자
  - 검사결과: ____________

[3. 타설 중 검측 항목]
- 항목 3.1: 슬럼프 시험 (현장 반입 시)
  - 검사기준: 설계 슬럼프 ±25mm
  - 입력 타입: 측정값(mm)
  - 측정값: ____________

- 항목 3.2: 공기량 시험
  - 검사기준: 설계 공기량 ±1.5%
  - 입력 타입: 측정값(%)

- 항목 3.3: 염화물 함유량
  - 검사기준: 0.30 kg/m³ 이하
  - 입력 타입: 측정값
  - 측정값: ____________

- 항목 3.4: 압축강도 시험용 공시체 채취 (150㎥당 1회 또는 1일 1회)
  - 검사기준: 표준양생 + 현장양생 공시체 각 6개
  - 입력 타입: 채취 수량
  - 채취 일시: ____________

- 항목 3.5: 타설 높이 및 자유낙하 높이 (1.5m 이하)
  - 입력 타입: 적합/부적합 체크

- 항목 3.6: 다짐(진동기) 사용 간격 (50cm 이내) 및 시간(5~15초)
  - 입력 타입: 적합/부적합 체크

- 항목 3.7: 콜드조인트 발생 여부
  - 검사기준: 이전 타설부와 2시간 이내 연속 타설
  - 입력 타입: 적합/부적합 체크

- 항목 3.8: 타설 순서 및 구획 준수
  - 입력 타입: 적합/부적합 체크

[4. 타설 후 검측 항목]
- 항목 4.1: 표면 마무리 (목재미장, 금속미장)
  - 입력 타입: 적합/부적합 체크
- 항목 4.2: 양생 방법 (습윤 양생 일수, 보온, 차폐)
  - 검사기준: 보통 시멘트 5일 / 조강 3일 / 중용열 7일 이상
  - 입력 타입: 일수 + 양생방법 텍스트
- 항목 4.3: 거푸집 해체 시기 (강도 발현 기준)
  - 검사기준: KDS 14 20 50 (측면 5MPa, 슬래브 14MPa 이상)
  - 입력 타입: 강도 측정값
- 항목 4.4: 양생 중 진동·하중 방지
  - 입력 타입: 적합/부적합 체크

[5. 시험 성과 (첨부)]
- 압축강도시험 성적서: 첨부 (28일 강도)
- 슬럼프시험 성적서: 첨부
- 염화물시험 성적서: 첨부
- 레미콘 송장: 첨부 (차량번호, 출하시간 포함)

[6. 종합판정]
- 종합 검측 결과: 적합 / 조건부 적합 / 부적합 (체크박스)
- 부적합 시 시정조치 내용: ____________
- 재검측 일시: ____________

[7. 서명란]
- 시공자(시공기술자) 점검: ____________ (인) — 자격: 건설기술인 (중급 이상)
- 시공자 현장대리인: ____________ (인) — 자격: 건설기술인 (특급/고급)
- 검측자 (감리원): ____________ (인) — 자격: 건설사업관리기술자
- 책임감리원 확인: ____________ (인) — 자격: 책임감리원 자격 (특급 + 교육)
