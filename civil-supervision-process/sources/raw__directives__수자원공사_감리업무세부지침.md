## 3. 핵심 절차 단계
1. **착수단계**
   - 수문·수리계산 재검토 (K-water 본사 수자원처 협조)
   - 가물막이·물돌리기 계획 검토 → 우기·갈수기 일정 조정
2. **시공단계**
   - 댐: 기초처리(그라우팅) → 콘크리트 타설(다짐 콘크리트 RCC 포함) → 차수벽
   - 정수장: 토목·기계·전기·계측 4분야 동시 진행 관리
   - 관로: 굴착 → 관 부설 → 수밀시험 → 되메우기
3. **중지점(Hold Point)**
   - 댐 기초: 암반 노출 확인 / 그라우팅 / 차수벽 시공 / 본체 콘크리트 리프트별
   - 정수장 수밀: 수밀시험 합격 후 되메우기
   - 관로: 관 부설 후 수압시험(설계압력 1.5배, 24시간) 합격
4. **시운전 / 통수시험**
   - 부분 시운전 → 전체 시운전 → 통수시험 → K-water 운영부서 인계

## 4. 서명 체인
- 댐 기초 암반 확인: 시공팀장 → 지반 감리원 → 책임감리원 → K-water 공사감독관 → 본사 댐기술팀(필요시)
- 콘크리트 타설(댐): 시공기사 → 품질관리자 → 분야 감리원 → 책임감리원 → 감독관 (리프트별 사진 첨부)
- 관로 수압시험: 시공팀장 → 기계 감리원 → 책임감리원 → K-water 감독관
- 정수장 시운전: 시운전반장 → 분야별 감리원 → 책임감리원 → K-water 운영처

## 5. 검측 빈도 정량 기준
- 댐 콘크리트: 리프트당 100㎥ 이내 1로트, 공시체 6개 (재령 7·28·91일)
- 댐 RCC: 50㎥당 1로트, 다짐도(VC 시험) 매 시간
- 그라우팅 주입량·압력: 공별 전수 기록, 흡수량(Lugeon) 1 Lu 이하 목표
- 수밀시험: 정수장 수조 - 24시간 후 수위강하 3mm 이하
- 관로 수압시험: 설계압력 1.5배, 24시간 유지, 압력강하 5% 이내
- 관 부설 정밀도: 평면 ±50mm, 수직 ±30mm (대구경 관 KP ±20mm)
- 정수장 도수로 통수단면: 설계 단면적의 ±2% 이내
- 안전점검: 매일 + 가물막이·수중작업 시 작업 전·후 추가

## 6. K-water 고유 추가 의무
- K-water 건설관리시스템 입력: 일일 1회
- 수질영향 모니터링 입회: 월 1회 (탁도·BOD·SS 측정)
- 댐 본체 타설 시 항온항습 환경관리 보고
- 환경영향평가 협의사항 이행여부 확인 보고: 분기 1회
- 운영부서 인계 시 시설관리매뉴얼·예비품 목록 검수 의무
