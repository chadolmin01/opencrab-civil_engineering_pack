# 건설공사 사진 및 동영상 촬영·관리 기준 — 국토교통부 — 출처: 국토교통부 「건설공사 사진 및 동영상 촬영지침」, 건설기술 진흥법 시행규칙 별표 · domain knowledge fallback — 수집일: 2026-05-28

## 1. 적용 범위
- 「건설기술 진흥법」 제62조 및 시행규칙 제58조에 따른 건설공사 사진관리
- 발주청·시공자·건설사업관리기술인이 공동 준수
- 영상·사진은 준공 후 5년간 보존(공공발주 10년), 변경·삭제 금지

## 2. 촬영 단계 (3단계 + 매몰부 추가)
1. **착수 전(Before)**: 작업 착수 직전 현황
2. **시공 중(During)**: 핵심 시공단계, 매몰·차폐 직전 필수
3. **완료 후(After)**: 작업 완료 직후, 다음 공정 착수 전

추가:
- **매몰부 촬영**: 매몰·은폐되는 부분(철근, 배관, 방수, 단열재)은 반드시 매몰 전 사진 + 동영상 의무
- **하자우려부**: 이음부, 접합부, 신축이음, 방수층 등

## 3. 촬영 빈도 정량 기준
| 공종 | 빈도 |
|---|---|
| 토공 | 절·성토 매 층(20~30cm)별 1회 + 다짐 후 1회 |
| 철근 배근 | 부재별 결속 완료 후 100% (배근도 비교 가능 각도) |
| 거푸집 | 설치 완료 시 면별 1회 (수직·수평 검측 동시) |
| 콘크리트 타설 | 타설 전·중(1시간 간격)·완료 후 / 양생 매일 |
| 매몰 배관 | 매몰 전 위치·심도가 보이도록 100% |
| 방수공사 | 바탕면·1차 도포·2차 도포·완료 후 4단계 |
| 마감공사 | 부재별 착수·완료 2단계 |
| 안전사고 | 발생 즉시·수습 중·복구 후 |

## 4. 촬영 사양 (정량 기준)
- 해상도: 최소 1,200만 화소(4000×3000) 이상
- 동영상: 1920×1080(FHD) 30fps 이상
- 메타데이터: EXIF에 촬영일시·GPS 좌표 필수 (위·변조 금지)
- 식별표지: 사진 내 표지판(공사명·공종·위치·일자·촬영자) 또는 디지털 워터마크
- 매몰부는 스케일바(자) 또는 측량봉 포함 촬영

## 5. 정리·제출 기준
- 일자별·공종별·위치별 폴더 분류
- 파일명: `YYYYMMDD_공종_위치_단계_일련번호.jpg`
- 사진대지(앨범): A4 1면 4장 이내, 캡션 필수
- 전자제출: 발주청 정보시스템 + 백업 매체(외장 HDD) 2부

## 6. 서명 체인
- 일일 촬영분: 촬영자(시공기사) → 현장대리인 → 감리원(매몰 전 100% 확인 서명)
- 매몰부: 감리원 입회 서명 없는 매몰은 재시공 사유
- 월별 사진대지: 시공사 품질관리자 → 책임감리원 → 발주청 감독관

## 7. 위반 시 조치
- 매몰부 사진 누락 → 재시공 또는 비파괴검사로 입증 의무
- EXIF 위·변조 적발 → 해당 공종 전체 재검측, 시공사 부실 벌점 부과
- 사진 미제출 → 기성검사 보류
