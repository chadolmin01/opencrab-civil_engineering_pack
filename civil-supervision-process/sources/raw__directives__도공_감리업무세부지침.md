# 한국도로공사 건설사업관리(감리) 업무 세부지침 — 한국도로공사(EX) — 출처: 한국도로공사 공시 지침 (ex.co.kr 자료실) · domain knowledge fallback — 수집일: 2026-05-28

## 1. 적용 범위
- 고속국도(고속도로), 일반국도 위탁구간, 휴게소·영업소·터널·교량 등 도로공사
- 「건설기술 진흥법」 및 「도로법」, 한국도로공사 「건설공사 감리업무 수행지침」
- 모든 고속도로 신설·확장·개축 공사: 책임감리(상주) 의무

## 2. 감리원 배치 정량 기준
| 공종 / 규모 | 책임감리원 | 분야 감리원 | 비고 |
|---|---|---|---|
| 본선 토공 5km 이상 | 1명(특급) | 토목·지반·환경 각 1명 | km당 보조감리 1명 |
| 교량 (연장 100m 이상 / PSC·강교) | 1명(특급) | 구조·재료 각 1명 | 가설공법별 전문감리원 |
| 터널 (연장 500m 이상) | 1명(특급) | 지반·환기·전기 각 1명 | 막장 1km당 1명 추가 |
| 포장 (아스팔트·콘크리트) | 1명(고급) | 재료·시공 각 1명 | 1일 생산량 1,000톤 기준 |

## 3. 핵심 절차 단계
1. **착수단계**
   - 공구별 감리단 구성 (착수 14일 전), 도공 건설처 승인
   - 시공계획서·품질관리계획서·안전관리계획서 동시 검토 (착수 30일 이내)
2. **시공단계**
   - 토공: 절·성토 층별 다짐 후 다짐도 시험 입회
   - 교량: 가설공법별 단계 확인(받침대 설치, 거더 가설, 슬래브 타설)
   - 터널: 막장 관찰(face mapping) 매일 1회, RMR/Q 분류
   - 포장: 혼합물 온도·다짐도 실시간 측정 입회
3. **중지점(Hold Point) 검측**
   - 노상 다짐 완료 / 보조기층 / 기층 / 표층 매 층별
   - 교량: 거푸집 설치 / 철근 배근 / PS 강선 긴장 / 콘크리트 타설 / 양생
   - 터널: 굴착 / 강지보재 설치 / 록볼트 / 1차 숏크리트 / 2차 라이닝
4. **준공·인계**
   - 사용 전 차량주행시험(평탄성 IRI) 입회
   - 도공 본사 합동준공검사 (준공 21일 전 예비)

## 4. 서명 체인
- 토공 다짐 시험: 시험원 → 품질관리기술자 → 분야 감리원 → 책임감리원 → 도공 공사감독관
- 교량 PS 긴장: 시공팀장 → 구조 감리원 → 책임감리원 → 도공 공사감독관 (반드시 입회 서명)
- 터널 막장 관찰: 시공기사 → 지반 감리원 → 책임감리원 → 도공 터널감독관 → 본사 지반전문위원(주 1회)
- 포장 일일 다짐도: 시공기사 → 재료 감리원 → 책임감리원 → 도공 감독관

## 5. 검측 빈도 정량 기준
- 토공 다짐도: 노상 1,000㎡당 5점 / 층두께 20cm 이하 / 다짐도 95% 이상
- 보조기층 다짐도: 1,000㎡당 5점 / 95% 이상 / 평탄성 ±20mm 이내
- 아스팔트 포장 코어채취: 1km당 5공 (포장두께 ±10mm, 다짐도 96% 이상)
- 시멘트 콘크리트 포장: 200㎥당 공시체 3개 (휨강도 4.5MPa 이상)
- 교량 콘크리트: 부재별 100㎥당 1로트, 강도시험 28일·재령별
- 터널 숏크리트 강도: 1차 50㎥당 1회, 2차 100㎥당 1회 / 압축강도 21MPa 이상
- 록볼트 인발시험: 100본당 3본, 설계인발력의 100% 이상
- 안전점검: 매일 + 발파작업 시 30분 전·후, 진동·소음 측정

## 6. 도공 고유 추가 의무
- 도공 건설관리정보시스템(EX-CMIS) 입력: 일일 1회 + 사진 일자별 업로드
- 막장관찰일지·일일다짐도성과표 본사 송부: 주 1회
- 안전·환경관리비 집행 사전승인 의무
- 도공 표준 시방서·구조계산기준 우선 적용 (KCS와 충돌 시 도공 기준)
