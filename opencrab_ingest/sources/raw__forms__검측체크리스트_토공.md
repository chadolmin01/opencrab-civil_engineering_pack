# 검측 체크리스트 — 토공사 (절토·성토·다짐) — 발행기관: 한국도로공사 / 국토교통부 / LH — 출처: https://www.molit.go.kr/LCMS/DWN.jsp (주요 공사별 점검 체크리스트), 한국도로공사 건설공사 전문시방서 — 수집일: 2026-05-28

## 표준 머리행
- Code No: ____________
- 검측일자: ____________ (YYYY-MM-DD)
- 공사명: ____________
- 공종: 토공사
- 부위별 세부공종: 절토 / 성토 / 노상 / 노체 / 다짐 / 사면보호 (체크)
- 위치: ____________ (스테이션 STA 0+000)
- 공사량: ____________ (m³)

[1. 일반정보]
- 현장명: ____________
- 시공사: ____________
- 측량기준점(BM): ____________
- 작업기간: ____________

[2. 절토 검측 항목]
- 항목 2.1: 절토 표고 (계획고)
  - 검사기준: 설계도서 ±50mm (노체 ±30mm)
  - 입력 타입: 측정값(m)

- 항목 2.2: 절토 폭(법선)
  - 검사기준: 설계 ±100mm
  - 입력 타입: 측정값

- 항목 2.3: 절토 비탈면 기울기
  - 검사기준: 설계도서 (예: 1:1.5)
  - 입력 타입: 측정값 비율

- 항목 2.4: 절토 지반 토질 확인 (지하수, 연약층)
  - 입력 타입: 적합/부적합 + 토질주상도 첨부

[3. 성토 검측 항목]
- 항목 3.1: 성토 재료 (토사, 암버럭) 적합성
  - 검사기준: 시방서 (입도, 액성한계, 소성지수, 다짐도)
  - 입력 타입: 시험성적서 첨부
  - 토질시험 결과: ____________

- 항목 3.2: 성토 1층 두께 (다짐 전)
  - 검사기준: 노체 300mm 이하, 노상 200mm 이하
  - 입력 타입: 측정값(mm)

- 항목 3.3: 성토 함수비
  - 검사기준: 최적함수비 OMC ±2~3%
  - 입력 타입: 측정값(%)

- 항목 3.4: 다짐도 (현장밀도시험)
  - 검사기준: 노체 90% / 노상 95% 이상 (실내 최대건조밀도 기준)
  - 입력 타입: 측정값(%)
  - 측정값: ____________ %

- 항목 3.5: 다짐장비 (롤러) 통과 횟수
  - 검사기준: 시방서 (보통 8회 이상)
  - 입력 타입: 횟수

- 항목 3.6: 평판재하시험 (PBT) / 현장CBR
  - 검사기준: 노상 K30 ≥ 100 MN/m³ (또는 CBR ≥ 10)
  - 입력 타입: 측정값
  - 측정값: K30 = ____ MN/m³

- 항목 3.7: 사면 기울기 및 단높이
  - 검사기준: 설계도서 (1:1.5 표준)
  - 입력 타입: 측정값

- 항목 3.8: 배수 처리 (소단, 종단배수)
  - 입력 타입: 적합/부적합

[4. 다짐 시험 빈도]
- 노체: 4,000m³당 1회 이상
- 노상: 1,000m² 또는 500m³당 1회 이상
- 다짐도 시험 횟수: ____ 회
- 시험위치: ____________

[5. 시험성과/첨부]
- 토질시험 성적서 (액성한계, 소성지수, 다짐시험 KS F 2312): 첨부
- 현장밀도시험 성적서 (KS F 2311): 첨부
- 평판재하시험 성적서 (KS F 2310): 첨부 (해당 시)
- 측량 야장 (종·횡단): 첨부

[6. 종합판정]
- 검측 결과: 적합 / 조건부 적합 / 부적합
- 조치사항: ____________

[7. 서명란]
- 시공자 (자격: 시공기술자): ____________ (인) — 자격: 건설기술인(토목)
- 토공작업 책임자 (장비 운전): ____________ (인) — 자격: 건설기계조종사
- 시험원 (현장시험): ____________ (인) — 자격: 토질시험기능사 또는 건설재료시험기사
- 감리원 (자격: 건설사업관리기술자): ____________ (인)
- 책임감리원 확인: ____________ (인)
