# KS D 3504 — 철근콘크리트용 봉강 (Steel bars for reinforced concrete) — 출처: domain knowledge — verified against KDS/KCS citations — 수집일: 2026-05-28

[적용 범위]
철근콘크리트용 이형철근(SD) 및 원형철근(SR)의 종류·치수·기계적 성질·시험 방법.

[종류 (이형철근) — 항복강도 등급]
- SD300 : 일반용
- SD400 : 일반용
- SD500 : 일반용
- SD600 : 일반용 (고강도)
- SD400W : 용접용
- SD500W : 용접용
- SD400S : 내진용
- SD500S : 내진용
- SD600S : 내진용

[원형철근]
- SR240 : 항복강도 240 MPa 이상
- SR300 : 항복강도 300 MPa 이상

[기계적 성질 — 이형철근]
- SD300 : 항복강도(fy) ≥ 300 MPa, 인장강도(fu) ≥ 440 MPa, 연신율 ≥ 16 % (D16 이하 18 %)
- SD400 : fy ≥ 400 MPa, fu ≥ 560 MPa, 연신율 ≥ 16 %
- SD500 : fy ≥ 500 MPa, fu ≥ 620 MPa, 연신율 ≥ 12 %
- SD600 : fy ≥ 600 MPa, fu ≥ 710 MPa, 연신율 ≥ 10 %
- SD400W : fy 400 ~ 520 MPa, fu ≥ 560 MPa
- SD500W : fy 500 ~ 620 MPa, fu ≥ 620 MPa

[내진용 추가 요건]
- 항복비(fy_실측 / fu_실측) : 1.25 이하 (SD400S, SD500S, SD600S)
- 항복강도 실측치 : 호칭치 + 130 MPa 이하

[화학 성분 (일반)]
- C : 0.30 % 이하 (SD400 기준)
- P : 0.040 % 이하
- S : 0.040 % 이하
- 탄소당량(Ceq) : 0.55 % 이하 (용접용 SDxxxW : 0.50 % 이하)

[표준 호칭 지름·단위 질량 (이형철근)]
- D10 : 9.53 mm, 0.560 kg/m, 단면적 71.33 mm²
- D13 : 12.7 mm, 0.995 kg/m, 단면적 126.7 mm²
- D16 : 15.9 mm, 1.56 kg/m, 단면적 198.6 mm²
- D19 : 19.1 mm, 2.25 kg/m, 단면적 286.5 mm²
- D22 : 22.2 mm, 3.04 kg/m, 단면적 387.1 mm²
- D25 : 25.4 mm, 3.98 kg/m, 단면적 506.7 mm²
- D29 : 28.6 mm, 5.04 kg/m, 단면적 642.4 mm²
- D32 : 31.8 mm, 6.23 kg/m, 단면적 794.2 mm²
- D35 : 34.9 mm, 7.51 kg/m, 단면적 956.6 mm²
- D38 : 38.1 mm, 8.95 kg/m, 단면적 1140 mm²
- D41 : 41.3 mm, 10.5 kg/m, 단면적 1340 mm²
- D51 : 50.8 mm, 15.9 kg/m, 단면적 2027 mm²

[굽힘 시험]
- D16 이하 : 굽힘각 180°, 굽힘 안지름 = 3d (SD300·SD400), 4d (SD500)
- D19 이상 : 굽힘각 180°, 굽힘 안지름 = 4d (SD300·SD400), 5d (SD500), 6d (SD600)
- 시험 후 균열 없을 것

[표시]
이형철근 표면에 제조사·종류(D 숫자 또는 색표시)·치수 표시.
