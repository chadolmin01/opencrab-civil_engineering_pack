# KS D 3503 — 일반 구조용 압연 강재 (Rolled steels for general structure) — 출처: domain knowledge — verified against KDS/KCS citations — 수집일: 2026-05-28

[적용 범위]
교량·선박·차량·기타 일반 구조물에 사용하는 열간 압연 강재(강판·강대·형강·평강·봉강).

[종류 — 항복강도 등급]
- SS235 (구 SS400 일부 대체) : 항복강도 ≥ 235 MPa, 인장강도 330 ~ 450 MPa
- SS275 (구 SS400 일부 대체) : 항복강도 ≥ 275 MPa, 인장강도 410 ~ 550 MPa
- SS315 : 항복강도 ≥ 315 MPa, 인장강도 490 ~ 630 MPa
- SS410 : 항복강도 ≥ 410 MPa, 인장강도 540 ~ 680 MPa
- SS450 : 항복강도 ≥ 450 MPa, 인장강도 590 ~ 740 MPa
- SS550 : 항복강도 ≥ 550 MPa, 인장강도 690 ~ 830 MPa

[기계적 성질 — 두께별 항복강도 (SS275 예시)]
- 16 mm 이하 : ≥ 275 MPa
- 16 mm 초과 40 mm 이하 : ≥ 265 MPa
- 40 mm 초과 100 mm 이하 : ≥ 245 MPa
- 100 mm 초과 : ≥ 235 MPa

[연신율 (SS275, KS B 0801 5호 시험편)]
- 두께 5 mm 이하 : ≥ 21 %
- 두께 5 mm 초과 16 mm 이하 : ≥ 23 %
- 두께 16 mm 초과 : ≥ 24 %

[화학 성분 제한 — SS275]
- C : 0.24 % 이하 (두께 50 mm 이하)
- P : 0.050 % 이하
- S : 0.050 % 이하
- 탄소당량(Ceq) : 제한 없음 (용접 보증 없음)

[굽힘 시험]
- 굽힘각 : 180°
- 굽힘 안지름 : 1.5t (SS235·SS275, t = 시험편 두께)
- 균열 없을 것

[제품 형태]
- 강판 (KS D 3503) : 두께 1.6 ~ 100 mm
- 형강 : H형강, I형강, ㄷ형강, 등변/부등변 ㄱ형강
- 평강·봉강

[표시]
강재 표면에 종류 기호·치수·제조사·롯트 번호 표시 또는 부착.

[참조]
KS B 0801 인장시험편, KS B 0802 인장시험 방법, KS B 0804 굽힘시험.

[참고 — 구 명칭 대응]
구 SS400 ≈ 신 SS275 (항복강도 기준 변경, 명칭 통일 2018년).
