# 검측 체크리스트 — 배수공 (맹암거·측구·집수정·U형 배수로) — 발행기관: 한국도로공사 / 국가철도공단 / LH 표준 검측체크리스트 — 출처: https://m.yesform.com/doc/form/158648 (배수공/맹암거 검측 체크 리스트), 한국도로공사 도로 배수공 시방서 — 수집일: 2026-05-28

## 표준 머리행
- Code No: ____________
- 검측일자: ____________ (YYYY-MM-DD)
- 공사명: ____________
- 공종: 배수공
- 부위별 세부공종: 측구 / 맹암거 / 종배수 / 횡배수 / 집수정 / U형 배수 (체크)
- 위치: ____________ (STA 0+000)

[1. 일반정보]
- 현장명: ____________
- 시공사: ____________
- 작업기간: ____________

[2. 검측 항목 — 일반]
- 항목 2.1: 굴착 깊이 (계획 표고)
  - 검사기준: 설계 ±30mm
  - 입력 타입: 측정값(mm)

- 항목 2.2: 굴착 폭 및 비탈
  - 검사기준: 설계 ±50mm
  - 입력 타입: 측정값

- 항목 2.3: 배수 종단경사 (구배)
  - 검사기준: 최소 0.3% 이상 (시방서 기준)
  - 입력 타입: 측정값(%)
  - 측정값: ____ %

- 항목 2.4: 기초 다짐도
  - 검사기준: 다짐도 ≥ 90% 또는 시방서
  - 입력 타입: 측정값(%)

- 항목 2.5: 기초 자갈/잡석 두께
  - 검사기준: 설계 ±20mm
  - 입력 타입: 측정값(mm)

[3. 검측 항목 — 맹암거]
- 항목 3.1: 유공관(드레인관) 규격 및 KS 확인
  - 검사기준: KS M 3408
  - 입력 타입: 적합/부적합 + 규격
  - 관경: ____ mm

- 항목 3.2: 유공관 부직포 감기
  - 검사기준: 시방서 (보통 200 g/㎡)
  - 입력 타입: 적합/부적합

- 항목 3.3: 필터재 (자갈/모래) 입도
  - 검사기준: 시방서 입도 분포
  - 입력 타입: 시험성적서 첨부

- 항목 3.4: 맹암거 깊이/폭
  - 검사기준: 설계 ±30mm
  - 입력 타입: 측정값

- 항목 3.5: 출구처리 (배수 토구) 위치
  - 입력 타입: 적합/부적합

[4. 검측 항목 — 측구/집수정]
- 항목 4.1: 콘크리트 강도 (현장 또는 PC제품)
  - 검사기준: fck ≥ 24 MPa (또는 시방서)
  - 입력 타입: 시험성적서 첨부

- 항목 4.2: 측구 규격 (높이, 폭, 두께)
  - 검사기준: 설계 ±10mm
  - 입력 타입: 측정값

- 항목 4.3: 이음부 처리 (지수재, 모르타르)
  - 입력 타입: 적합/부적합

- 항목 4.4: 집수정 깊이/내경
  - 검사기준: 설계 ±30mm
  - 입력 타입: 측정값

- 항목 4.5: 그레이팅 (집수 격자) 규격 및 설치
  - 검사기준: KS D 3504, 하중등급
  - 입력 타입: 적합/부적합

- 항목 4.6: 뒷채움 다짐
  - 검사기준: 다짐도 ≥ 90%
  - 입력 타입: 측정값(%)

[5. 시험성과/첨부]
- 골재 입도시험: 첨부 (해당 시)
- 콘크리트 압축강도 시험: 첨부
- 측량 야장: 첨부

[6. 종합판정]
- 검측 결과: 적합 / 조건부 적합 / 부적합
- 조치사항: ____________

- 감리원 (자격: 건설사업관리기술자): ____________ (인)
- 책임감리원 확인: ____________ (인)
