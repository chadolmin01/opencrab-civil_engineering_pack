- 항목 2.1: 거푸집 자재 상태 (균열, 휨, 부식, 손상)
  - 검사기준: 재사용 횟수 이내, 손상 5% 미만
  - 입력 타입: 적합/부적합
  - 검사결과: ____________

- 항목 2.2: 박리제 도포 상태
  - 검사기준: 균일 도포, 철근/매립물 오염 없음
  - 입력 타입: 적합/부적합

- 항목 2.3: 거푸집 설치 수직도
  - 검사기준: 1/500 이내, 절대값 ≤ 25mm
  - 입력 타입: 측정값(mm)
  - 측정값: ____________

- 항목 2.4: 거푸집 평면 위치 (통심, 변심)
  - 검사기준: ±10mm 이내 (KDS 14 20 10)
  - 입력 타입: 측정값(mm)
  - 측정값: ____________

- 항목 2.5: 거푸집 단면 치수
  - 검사기준: 설계도서 ±5mm
  - 입력 타입: 측정값(mm)
  - 검사결과: ____________

- 항목 2.6: 동바리 (서포트) 설치 간격 및 수직도
  - 검사기준: 설계기준, 좌굴길이 이내, 수직 1/200
  - 입력 타입: 측정값
  - 동바리 종류: 강관 / 시스템 / 목재 (체크)
  - 설치 간격: ____________ mm

- 항목 2.7: 동바리 받침판/이음 상태
  - 검사기준: 콘크리트 받침, 이음부 4본 이상 볼트체결
  - 입력 타입: 적합/부적합

- 항목 2.8: 수평 연결재 및 가새 설치
  - 검사기준: 높이 2m 이내마다 수평 연결, X형 가새
  - 입력 타입: 적합/부적합

- 항목 2.9: 거푸집 긴결재 (폼타이, 세퍼레이터) 간격
  - 검사기준: 600mm 이내, 설계도서
  - 입력 타입: 측정값

- 항목 2.10: 거푸집 청소 (이물질, 톱밥, 결속선 제거)
  - 입력 타입: 적합/부적합

- 항목 2.11: 거푸집 누수 방지 (조립부 틈새 막음)
  - 입력 타입: 적합/부적합

- 항목 2.12: 매립물 위치 및 고정
  - 검사기준: 설계도서 위치 ±5mm
  - 입력 타입: 적합/부적합

- 항목 2.13: 거푸집 표면 청결 및 마감면 평탄도
  - 검사기준: 3m 직선자 5mm 이내
  - 입력 타입: 측정값

- 항목 2.14: 가설 작업발판 및 안전난간
  - 검사기준: 산업안전보건기준규칙 (난간 90~120cm)
  - 입력 타입: 적합/부적합
