# 건설현장 안전점검 보고서 (일일·주간·월간 안전점검) — 발행기관: KOSHA / 국토안전관리원 / 고용노동부 — 출처: https://www.safety.or.kr/safety/main/contents.do?menuNo=200067 (대한산업안전협회 건설공사 안전점검), https://www.kosha.or.kr/ (KOSHA 자료), 건설기술 진흥법 시행령 제100조 (건설공사 안전점검) — 수집일: 2026-05-28

## 점검 종류 및 주기
1. **자체 안전점검** (일일/주간) — 시공자 자율
2. **정기 안전점검** (분기별) — 건설사업관리기술자
3. **정밀 안전점검** (필요 시) — 안전진단전문기관 / 국토안전관리원
4. **초기점검** (착공 시) / **수시점검** (특정 위험 시)
