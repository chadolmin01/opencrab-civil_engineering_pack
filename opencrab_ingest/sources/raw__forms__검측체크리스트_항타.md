# 검측 체크리스트 — 항타공사 (PHC 파일 / 강관파일 / 시험항타) — 발행기관: LH / 한국도로공사 표준 / KOSHA 안전점검 — 출처: https://www.thinkzon.com/share_biz/103637 (교량공 PHC 검측체크리스트), https://pumjil.lh.or.kr/ (LH 품질관리지침) — 수집일: 2026-05-28

## 표준 머리행
- Code No: ____________
- 검측일자: ____________ (YYYY-MM-DD)
- 공사명: ____________
- 공종: 항타공사 (기초공사)
- 부위별 세부공종: 시험항타 / 본항타 / 두부정리 (체크)
- 위치: ____________ (구조물명, 통선, 파일번호)

[1. 일반정보]
- 현장명: ____________
- 시공사: ____________
- 항타 종류: PHC파일 / 강관파일 / SCP / SIP / DRA / RCD (체크박스)
- 파일 규격: 직경 ____ mm × 길이 ____ m
- 설계 지지력: ____________ tonf
- 설계 관입깊이: ____________ m
- 시공 일자: ____________

[2. 시험항타(시항타) 검측 항목]
- 항목 2.1: 시험항타 위치 선정 (지반조건 대표성)
  - 검사기준: 시방서, 보통 3~5본
  - 입력 타입: 위치 + 적합/부적합

- 항목 2.2: 항타기 제원 확인 (해머 중량, 낙하고)
  - 검사기준: 설계 적용 해머와 일치
  - 입력 타입: 텍스트
  - 해머종류: 디젤 / 유압 / 드롭 (체크)
  - 해머중량: ____ tonf, 낙하고: ____ m

- 항목 2.3: 파일 자재 확인 (KS 인증, 강도)
  - 검사기준: KS F 4306 (PHC), KS F 4602 (강관)
  - 입력 타입: 적합/부적합 + 시험성적서 첨부

- 항목 2.4: 파일 운반·취급 상태 (균열, 손상)
  - 검사기준: 길이방향 균열 폭 0.2mm 이내, 모서리 파손 없음
  - 입력 타입: 적합/부적합

- 항목 2.5: 항타 수직도
  - 검사기준: 1/100 이내 (해상 시 1/50)
  - 입력 타입: 측정값
  - 측정값: ____________ /100

- 항목 2.6: 항타 위치 정확도 (계획위치 대비 편심)
  - 검사기준: 100mm 이내 (구조물 종류별 시방)
  - 입력 타입: 측정값(mm)

- 항목 2.7: 최종 관입량 (Rebound 측정)
  - 검사기준: 동역학 공식 (Hiley), 최종 관입량 10~20mm/10타
  - 입력 타입: 관입량(mm/10타) + 리바운드(mm)
  - 측정값: ____________ mm

- 항목 2.8: 동재하시험 (PDA) 또는 정재하시험 결과
  - 검사기준: 설계지지력 이상 (안전율 2.0~3.0)
  - 입력 타입: 시험성적서 첨부
  - 측정 지지력: ____ tonf

- 항목 2.9: 시간경과효과(Set-up) 측정
  - 검사기준: 항타 후 24시간 이상 경과 후 재시험
  - 입력 타입: 측정값

[3. 본항타 검측 항목]
- 항목 3.1: 항타 일자별 시공 본수, 관입 깊이
  - 입력 타입: 표 입력 (파일번호, 길이, 관입깊이, 관입량)

- 항목 3.2: 항타 순서 (계획대로 — 중앙→외곽 또는 반대)
  - 입력 타입: 적합/부적합

- 항목 3.3: 인접파일 영향 (Heaving, 측방유동)
  - 검사기준: 헤브 ±10mm 이내
  - 입력 타입: 측정값

- 항목 3.4: 항타 중 균열·파손 발생 여부
  - 입력 타입: 적합/부적합 + 발생 시 사진

- 항목 3.5: 항타 소음·진동 측정
  - 검사기준: 소음진동관리법 (주거지 65dB 이하 등)
  - 입력 타입: 측정값(dB, mm/s)
  - 소음: ____ dB, 진동: ____ mm/s

- 항목 3.6: 안전조치 (항타기 점검, 권상 와이어, 샤클)
  - 검사기준: KOSHA Guide / 산업안전보건기준규칙
  - 입력 타입: 적합/부적합

- 항목 3.7: 기름 비산 방지 조치
  - 입력 타입: 적합/부적합

[4. 두부정리 검측 항목]
- 항목 4.1: 컷오프 레벨 (절단 표고)
  - 검사기준: 설계도서 ±20mm
  - 입력 타입: 측정값(mm)

- 항목 4.2: 두부 보강 철근 노출 길이
  - 검사기준: 설계도서대로
  - 입력 타입: 측정값(mm)

- 항목 4.3: 콘크리트 충진 (PHC파일 속채움)
  - 검사기준: 시방서 충진 깊이
  - 입력 타입: 측정값(m)

[5. 시험성과/첨부]
- PDA(동재하) 시험성적서: 첨부
- 정재하시험 성적서: 첨부 (해당 시)
- 항타 야장 (Driving Log): 첨부 필수
- 파일 시험성적서: 첨부

[6. 종합판정]
- 검측 결과: 적합 / 조건부 적합 / 부적합
- 조치사항: ____________
- 추가시험/대체파일 요부: ____________

[7. 서명란]
- 시공자 (자격: 시공기술자): ____________ (인) — 자격: 건설기술인(토목) 중급 이상
- 항타작업 책임자 (특별교육 이수자): ____________ (인) — 자격: 항타기 운전기능사 / 특별안전교육 이수자
- 시험기관 (PDA 시험기관): ____________ (인) — 자격: 지반기술사 또는 공인시험기관
- 감리원 (자격: 건설사업관리기술자): ____________ (인)
- 책임감리원 확인: ____________ (인) — 자격: 책임감리원 (특급 + 토목·구조)
