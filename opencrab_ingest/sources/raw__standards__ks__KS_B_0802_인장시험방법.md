# KS B 0802 — 금속재료 인장 시험 방법 (Method of tensile test for metallic materials) — 출처: domain knowledge — verified against KDS/KCS citations — 수집일: 2026-05-28

[적용 범위]
실온에서 금속재료의 인장 특성(항복강도·인장강도·연신율·단면수축률)을 결정하는 방법.

[시험 온도]
- 표준 : 10 °C ~ 35 °C
- 정밀 시험 : 23 ± 5 °C

[시험기]
- 분류 : 등급 1 (정밀도 ± 1 %) 권장
- 하중 정밀도 : 측정 범위의 ± 1 % 이내
- 그립 동축도 : 시험편 축과 하중축 일치

[변형 속도 — 인장 속도]
- 탄성역 : 응력 속도 6 ~ 60 MPa/s (또는 변형률 속도 0.00025 ~ 0.0025/s)
- 항복점 부근 : 변형률 속도 ≤ 0.0025/s 권장
- 항복 이후 : 변형률 속도 0.008/s 이하 (강재)
- 일정 변형률 제어 권장

[항복강도(YS) 결정 방법]
1. 상부·하부 항복점이 명확한 경우 : 상부 항복점(ReH) 또는 하부 항복점(ReL) 보고
2. 항복이 불명확한 경우 : 영구 변형 0.2 % 오프셋(Rp0.2) 사용
3. 일부 재료 : 0.5 % 전 변형(Rt0.5) 사용

[인장강도(TS, Rm) 결정]
시험 중 최대 하중을 시험편 초기 단면적으로 나눈 값. MPa 단위, 1 MPa 단위로 보고.

[연신율(EL) 결정]
- 파단 후 시험편을 맞대어 표점 거리(Lu) 측정
- EL = (Lu - Lo) / Lo × 100 (%)
- 파단 위치가 표점 중앙에서 1/3 이내일 것, 아니면 측정값 무효 또는 시프트 표점법 사용

[단면수축률(RA) 결정]
- 파단부 최소 단면적(Au) 측정
- RA = (Ao - Au) / Ao × 100 (%)
- 원형 단면에서 직각 2방향 측정 평균

[측정 정밀도]
- 치수 : 0.01 mm (지름), 0.02 mm (판 두께)
- 게이지 길이 : 0.5 % 이내
- 하중 : 최대 하중의 0.5 % 이내

[유효성]
- 시험편 그립부에서 파단 시 무효
- 시험편 표점 외에서 파단 시 무효 (단, 강도값은 유효)

[보고 항목]
재료 명칭, 시험편 종류·치수, 시험 온도, 인장 속도, ReH/ReL/Rp0.2, Rm, EL, RA, 파단 위치, 파단 형태.

[참조]
KS B 0801 인장 시험편, KS D 3504 철근, KS D 3503 일반 구조용 강재.
