## 1. 법적 근거 및 적용 범위

- 시특법 시행령 별표 1 (1종·2종·3종 시설물 범위): 옹벽 (높이 5 m 이상 도로·철도 옹벽 = 2종)
- 「사면 안정 설계기준」 KDS 11 70 05
- 「옹벽 설계기준」 KDS 11 80 05
- 「급경사지 재해예방에 관한 법률」: 급경사지 안전점검 연계

---

## 2. 옹벽 분류 및 시설물 종별

| 옹벽 종류 | 특성 |
|---------|-----|
| 중력식 옹벽 | 자중으로 토압 저항, 소규모 |
| 반중력식 옹벽 | 중간 형태 |
| 캔틸레버 옹벽 | 역T형, 높이 6~8 m 이하 적합 |
| 부벽식 옹벽 | 지지벽 설치, 높이 8 m 이상 |
| 보강토 옹벽 | 지오그리드+전면판 구성 |

---

## 3. 옹벽 정밀안전진단 조사 항목

### 3.1 외관조사

| 부재 | 주요 점검 항목 |
|-----|------------|
| 본체 (전면벽) | 균열·박락·기울음·변위 |
| 기초 | 세굴·침하·노출 |
| 배면 | 배수구 막힘·침윤선 상승 |
| 신축이음 | 이음 상태·이격·단차 |
| 배수 시설 | 배수공·집수정·유공관 기능 |

### 3.2 정밀조사·시험

- 콘크리트 압축강도: 코어 채취 φ100 mm
- 반발경도시험: 3~5점/구역 평균
- 기울음 측량: 수직도 측정 (광파측량·레이저)
- 침하 측량: 수준측량 ±3 mm 정밀도
- 지하수위 측정: 수위계 설치 (필요 시)

## 4. 옹벽 정량 기준

### 4.1 균열 폭 기준 (콘크리트 옹벽)

| 균열 폭 | 등급 |
|--------|-----|
| 0.2 mm 미만 | A~B |
| 0.2~0.3 mm | C |
| 0.3~0.5 mm | D |
| 0.5 mm 초과 | E |

### 4.2 기울음 허용 기준

| 기울음 비율 | 등급 |
|----------|-----|
| H/200 이하 | A~B |
| H/200 ~ H/100 | C |
| H/100 ~ H/50 | D |
| H/50 초과 | E (즉시 보강) |

### 4.3 배수공 기능 기준

| 배수공 막힘률 | 판정 |
|-----------|-----|
| 0% | 정상 (A) |
| 10% 이하 | 경미한 유지관리 필요 (B) |
| 10~30% | 보수 필요 (C) |
| 30~50% | 긴급 청소·보수 (D) |
| 50% 초과 또는 전면 막힘 | E (즉각 조치) |

### 4.4 안전율 기준 (옹벽 구조검토)

| 파괴 모드 | 최소 안전율 |
|---------|----------|
| 활동 | 1.5 이상 |
| 전도 | 2.0 이상 (비연암) |
| 지지력 | 3.0 이상 |
| 내진 시 (활동) | 1.1 이상 |

## 5. 사면 정밀안전진단 조사 항목

### 5.1 사면 분류

| 분류 | 해당 사면 |
|-----|---------|
| 자연사면 | 자연 지반 그대로인 사면 |
| 절토사면 | 도로·철도 개설 시 깎은 사면 |
| 성토사면 | 토공으로 쌓은 사면 |
| 암반사면 | 암반이 주요 구성 지반인 사면 |

### 5.2 외관조사 항목

| 항목 | 조사 내용 |
|-----|---------|
| 사면 변형 | 균열·함몰·융기·단차 |
| 식생 상태 | 고사·탈락·노출 지반 |
| 배수 상태 | 배수구 막힘·용출수 |
| 낙석 흔적 | 낙석 크기·빈도 |
| 안정 시설 | 낙석방지망·앵커·록볼트 상태 |

### 5.3 정밀조사·시험

- 토질 시험: 전단강도 (직접전단시험 KS F 2343, UU삼축압축시험)
- 암석 시험: 일축압축강도 (KS F 2519)
- 지반조사: 표준관입시험(SPT)·시추조사
- 지하수위 조사: 지하수위계 설치
- 불연속면 조사: 주향·경사·간격·거칠기·충전물

## 6. 사면 안전성 평가 기준

### 6.1 사면 안전율 기준 (한계평형해석)

| 조건 | 최소 안전율 |
|-----|----------|
| 건기 (정상 침투) | 1.5 이상 |
| 우기 (포화상태) | 1.2 이상 |
| 지진 시 | 1.1 이상 |
| 복구 시 임시 | 1.1 이상 |

### 6.2 암반사면 평면 파괴 기준

| 조건 | 판정 |
|-----|-----|
| 파괴면 경사각 < 마찰각 | 안전 |
| 파괴면 경사각 ≥ 마찰각 | 불안정 위험 |
| 대책공 설치 후 안전율 < 1.2 | D~E 등급 |

### 6.3 사면 경사각 경험적 기준

| 지반 종류 | 안정 경사 |
|---------|---------|
| 토사 (자연) | 1:1.5 ~ 1:2.0 (경사 27~34°) |
| 풍화암 | 1:1.0 ~ 1:1.2 |
| 경암 | 1:0.3 ~ 1:0.5 |
| 연암 (불량 불연속면) | 1:0.8 ~ 1:1.0 |

## 8. 보강토 옹벽 특별 점검 기준

| 점검 항목 | 이상 기준 |
|---------|---------|
| 전면판 불균등 침하 | 인접 패널 간 단차 25 mm 초과 |
| 전면판 기울음 | 수직도 1/100 초과 |
| 전면판 균열 | 0.3 mm 이상 관통균열 |
| 상단 침하 | 10 mm 이상 |
| 배수 불량 | 침윤선 상승 → 전면 습윤 |

## 9. 급경사지 연계 점검 (급경사지 재해예방법)

- 대상: 경사도 34° (수직 높이 5 m) 이상 자연사면·절토사면
- 점검 주기: 연 1회 이상 (안전점검)
- 위험등급: 1~5등급 (5등급 = 가장 위험)
- 5등급 → 급경사지 붕괴 위험지역 지정 → 주민 대피 계획 수립
