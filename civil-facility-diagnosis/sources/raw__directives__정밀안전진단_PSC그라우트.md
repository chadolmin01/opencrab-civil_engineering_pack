# 정밀안전진단 PSC 그라우트 충전도 진단 가이드 — 출처: 도메인 지식 / 시설물 안전법 정밀안전진단 세부 지침 / KISTEC 비파괴 진단 가이드 기반 — 수집일: 2026-05-28

## 개요

프리스트레스트 콘크리트(PSC) 교량의 포스트텐션(Post-tension) 덕트 내 그라우트(grout) 충전 불량은 강선(tendon) 부식 및 파단으로 이어져 교량 붕괴의 직접 원인이 될 수 있다. 그라우트 미충전(void)·공동(cavity)은 덕트 내 수분 침입 및 염화물 농축을 촉진하며, 국내에서는 준공 후 10~20년 경과 교량을 중심으로 미충전 사례가 다수 발견되고 있다. 진단은 충격탄성파(Impact Echo, IE)·임팩트에코·GPR·내시경(보어스코프) 등 비파괴 기법을 복합 적용한다.

## 정량 기준

### 충전 상태 판정 등급

| 판정 등급 | 미충전·공동 비율 (덕트 단면 기준) | 조치 |
|---|---|---|
| A (양호) | **< 5 %** | 유지 관리 |
| B (주의) | **5 ~ 20 %** | 정밀 추적 조사, 보수 계획 수립 |
| C (불량) | **20 ~ 50 %** | 긴급 추가 그라우팅 보수 |
| D (심각) | **> 50 %** | 즉시 구조 안전성 평가·사용 제한 검토 |

### 강선 부식 평가 기준

| 상태 | 판정 |
|---|---|
| 부식 없음, 광택 유지 | 정상 |
| 표면 점청(点靑), 피팅(pitting) | 경미 부식, 단면 손실 추정 < 5 % |
| 가용성 부식(uniform), 단면 감소 확인 | 중간 부식, 추가 인장 능력 확인 |
| 국부 단면 손실 **≥ 5 %** (단선 포함) | 심각 → 즉시 보강 또는 교체 |
| 강선 파단 (단선) | 긴급 → 통행 제한 및 즉시 구조 평가 |

### 검사 주기 (시설물 등급별)

| 시설물 등급 | 권장 PSC 그라우트 진단 주기 |
|---|---|
| 1등급 교량 | **10년마다** 전체 구간 진단 |
| 2·3등급 교량 | **5~7년마다** |
| 준공 후 25년 이상 경과 | **5년마다** (등급 무관) |

## 검사·시험 방법

### 1단계 — 충격탄성파(Impact Echo, IE) 검사

1. 원리: 금속 임팩터로 콘크리트 표면 타격 → 발생 탄성파가 덕트 경계면에서 반사 → 주파수 분석으로 공동 여부 판별
2. 측정 격자: 덕트 방향 따라 **0.2 ~ 0.5 m 간격**
3. 판정: 그라우트 충전 구간은 고주파(시멘트·강선 반사), 공동 구간은 저주파(공기 반사) 피크 출현
4. 신호 분석: FFT(Fast Fourier Transform) 주파수 스펙트럼, 공동 예측 깊이 = Vp / (2 × 피크 주파수)
   - Vp (콘크리트 P파 속도) ≈ 4,000 m/s (현장 보정 필요)

### 2단계 — 임팩트에코 어레이 스캐닝 (IE-Array)

1. 다채널 IE 어레이 장비로 연속 스캐닝
2. 2차원 단면 이미지(B-scan) 생성 → 공동 위치·크기 시각화
3. 검사 속도: 배관 방향 4 ~ 10 m/시간

### 3단계 — GPR(지면투과레이더) 탐사

1. 주파수 선택: 덕트 깊이 **0 ~ 200 mm** → 2.0 GHz 안테나, **200 ~ 400 mm** → 1.0 GHz
2. 그라우트 충전 양호 시: 덕트 위치에서 강한 반사 + 내부 신호 약함
3. 공동 존재 시: 공기-그라우트 경계에서 강한 이중 반사 신호
4. 한계: 철근 밀도 높은 부위에서 신호 산란 → IE와 병행 권장

### 4단계 — 내시경(보어스코프) 직접 확인

1. 덕트 위치에 φ25 ~ 40 mm 드릴링 (선행 IE/GPR로 위치 확정 후 천공)
2. 방수형 내시경 카메라 삽입 → 그라우트 충전 상태·강선 부식 직접 관찰
3. 기록: HD 영상 저장 및 부식 등급·충전율 정량 평가
4. 천공 후: 고성능 그라우트(w/c ≤ 0.40) 재충전 및 마감

## 합격 기준

| 검사 항목 | 합격 기준 |
|---|---|
| 그라우트 미충전 비율 (IE/GPR) | < 5 % (A 등급) |
| 강선 부식 | 표면 점청 허용, 단면 손실 < 5 % |
| 내시경 확인 강선 상태 | 단선 없음, 부식 경미 이하 |
| IE 피크 주파수 | 공동 지시 피크 부재 (설계 덕트 반사 주파수 확인) |
