# 정밀안전진단 AAR(알칼리-골재 반응) 진단 기법 가이드 — 출처: 도메인 지식 / KS F 2545 / ASTM C856 / 시설물 안전법 시행규칙 기반 — 수집일: 2026-05-28

## 개요

알칼리-골재 반응(Alkali-Aggregate Reaction, AAR)은 시멘트 공극수 내 알칼리 이온(Na⁺·K⁺)이 골재 내 반응성 실리카(비정질 실리카·오팔·플린트)와 반응하여 알칼리-실리카 겔(ASR gel)을 생성하고, 이 겔이 수분 흡수 시 팽창하여 콘크리트 균열·박리를 유발하는 내구성 열화 기전이다. 교량 교각·댐·항만 구조물 등 장수명 대형 콘크리트 구조물에서 주로 발생하며, 초기 진단이 지연될 경우 구조 내력 저하로 이어진다.

## 정량 기준

### 알칼리-실리카 반응성 분류 (KS F 2546 기준)

| 판정 | 모르타르 바 팽창량 (28일) | 조치 |
|---|---|---|
| 무해 (Non-reactive) | < **0.10 %** | 조치 불필요 |
| 잠재적 반응성 (Potentially reactive) | **0.10 ~ 0.20 %** | 억제재 사용 검토 |
| 반응성 (Reactive) | > **0.20 %** | 반응성 골재 사용 금지 또는 억제재 필수 적용 |

### 현장 진단 지표

| 진단 지표 | 허용 기준 / 주의 기준 |
|---|---|
| 균열 폭 (망상 균열·map cracking) | 0.2 mm 초과 시 진단 대상 |
| 표면 팽창·박리 면적 | 슬래브 면적의 **5 %** 초과 시 정밀 조사 |
| 겔 삼출(gel exudation) | 육안 식별 시 즉시 시료 채취 |
| pH 지시 (페놀프탈레인 반응) | 균열면 적색 발색 → 알칼리 잔존 확인 |

### 잔존 팽창 잠재량 평가 (코어 시험)

| 시험 조건 | 판정 기준 |
|---|---|
| 38 ℃ × 100 % RH 보관 후 1년 팽창 | **0.04 %** 이하: 팽창 안정 |
| 38 ℃ × 100 % RH 보관 후 1년 팽창 | **0.04 ~ 0.12 %**: 모니터링 강화 |
| 38 ℃ × 100 % RH 보관 후 1년 팽창 | **> 0.12 %**: 보수·보강 필수 |

## 검사·시험 방법

### 1단계 — 육안 및 페놀프탈레인 검사

1. 균열 형태 확인: 망상 균열(map cracking), 줄무늬 방향성 균열(일방향 AAR) 확인
2. 균열 폭 측정: 크랙 게이지(정밀도 0.01 mm)로 대표 균열 10개 이상 측정
3. 페놀프탈레인 시험: 균열면 1 % 페놀프탈레인 알코올 용액 도포 → 적색 발색 여부 확인

### 2단계 — 코어 채취 및 편광현미경(PLM) 분석

1. 코어 직경 **φ100 mm**, 깊이 **100 mm 이상** 채취 (ASTM C856)
2. 박편 제작 (두께 30 μm) → 편광현미경 관찰
3. 확인 사항: 반응 테두리(reaction rim), 겔 침착(gel deposit), 실리카 용해 흔적

### 3단계 — 주사전자현미경(SEM) 및 EDS 분석

1. SEM으로 겔 형태 및 분포 관찰 (배율 500~5,000×)
2. EDS(Energy Dispersive Spectroscopy)로 원소 성분 분석: Si·Ca·Na·K 비율로 ASR 겔 확인
3. 알칼리 함량 측정: 시멘트 Na₂Oeq ≥ **0.6 %** 이상 시 고알칼리 시멘트 분류

### 4단계 — 잔존 팽창 잠재량 시험

1. 코어를 습도 100 %, 38 ℃ 항온항습기에 보관
2. 3개월마다 길이 변화 측정 (최소 1년간)
3. ASTM C1293 또는 CSA A23.2-14A 방법 준용

## 합격 기준

| 판정 항목 | 합격 (안정) 기준 |
|---|---|
| 모르타르 바 팽창 | 28일 < 0.10 % |
| 코어 잔존 팽창 | 1년 < 0.04 % |
| 균열 폭 | ≤ 0.2 mm (구조 안전 영향 없는 경우) |
| PLM/SEM 관찰 | 겔 삼출·반응 테두리 미확인 |

## 관련 표준 인용

- KS F 2546 알칼리-실리카 반응성 시험 (모르타르 바 방법)
- KS F 2545 화학적 방법에 의한 골재의 알칼리 실리카 반응성 시험
- ASTM C856 콘크리트 코어 박편 분석 방법
- ASTM C1293 콘크리트 프리즘 팽창 시험
- 시설물의 안전 및 유지관리에 관한 특별법 시행규칙 (정밀안전진단 세부 지침)
