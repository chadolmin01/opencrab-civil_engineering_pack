# 정밀안전진단 강박스 거더 내부 검사 가이드 — 출처: 도메인 지식 / 시설물 안전법 정밀안전진단 세부 지침 / KOSHA 밀폐공간 기준 기반 — 수집일: 2026-05-28

## 개요

강박스 거더(Steel Box Girder) 내부는 밀폐 공간(Confined Space)으로 분류되며, 산소 결핍·유해가스·협소한 출입 경로 등 복합적인 위험 요소를 가진다. 정밀안전진단 시 내부 도막 열화·부식·균열·좌굴·피로 균열을 직접 육안 검사하며, 접근 경로 확보·환기·산소 농도 확인이 선행되어야 한다. 강박스 교량은 도입 후 20년 이상 경과 시 내부 부식 진행이 가속되므로 정기적 내부 진단이 필수다.

## 정량 기준

### 밀폐 공간 출입 전 환경 기준

| 측정 항목 | 안전 기준값 | 위험 기준값 |
|---|---|---|
| 산소 농도 | **18 % 이상** | < 18 % → 즉시 출입 금지 |
| 황화수소(H₂S) | **< 10 ppm** | ≥ 10 ppm → 출입 금지 |
| 일산화탄소(CO) | **< 25 ppm** | ≥ 25 ppm → 출입 금지 |
| 가연성 가스 | **< LEL 10 %** | ≥ LEL 10 % → 즉시 대피 |

### 부식 등급 및 판정 기준

| 부식 등급 | 도막 손상·부식 상태 | 조치 |
|---|---|---|
| Ri 0 | 부식 없음, 도막 양호 | 다음 주기까지 유지 |
| Ri 1 | 부식 발생 면적 < **0.05 %** | 부분 보수 |
| Ri 2 | 부식 면적 **0.05 ~ 0.5 %** | 국부 도장 보수 |
| Ri 3 | 부식 면적 **0.5 ~ 1 %** | 광범위 도장 보수 |
| Ri 4 | 부식 면적 **1 ~ 8 %** | 전면 재도장 계획 |
| Ri 5 | 부식 면적 **> 8 %** | 즉시 전면 재도장·구조 평가 |

(ISO 4628-3 부식 등급 기준 준용)

### 강재 두께 감소 한계

| 판정 | 두께 감소율 |
|---|---|
| 이상 없음 | < **5 %** |
| 주의 (모니터링 강화) | **5 ~ 10 %** |
| 보수 필요 | **10 ~ 20 %** |
| 구조 안전성 평가 의뢰 | **> 20 %** |

### 검사 주기

| 시설물 등급 | 정밀안전점검 주기 | 정밀안전진단 주기 |
|---|---|---|
| 1등급 | 4년에 1회 이상 | 6년에 1회 이상 |

## 검사 절차

### 1단계 — 출입 전 안전 확보

1. 밀폐 공간 작업허가서 발행 (감리·안전관리자 서명)
2. 4가스 복합 측정기로 산소·CO·H₂S·LEL 측정 및 기록
3. 강제 환기: 축류 팬 또는 덕트 팬으로 내부 공기 **3회 이상** 교체 후 재측정
4. 구조원(감시원) 외부 배치: 내부 작업자와 **10분마다** 무선 연락 유지

### 2단계 — 조명 및 접근로 설치

1. 내부 조명: **500 lux 이상** (검사 면 기준) — 방폭형 또는 저전압(12 V·24 V) LED
2. 접근 사다리·발판: 추락 방지 안전 난간 설치, 이동 통로 폭 **0.6 m 이상**
3. 구명줄 착용 (전신 하네스) — 출입구에서 내부 작업자까지 연결

### 3단계 — 내부 육안 및 계측 검사

1. **도막 열화**: 박리·기포·균열·변색 면적 격자 구획 (1 m × 1 m) 기록
2. **부식**: Ri 등급 분류, 사진 촬영 (GPS 태그 포함)
3. **균열**: 크랙 게이지로 폭 측정, 자분탐상(MT) 또는 침투탐상(PT)으로 표면 균열 확인
4. **좌굴·변형**: 직선자·수평기로 변형량 측정, 기준점 대비 처짐 계산
5. **강재 두께**: 초음파 두께 측정기(UT) — 격자 1 m마다 1점 측정, 감육 부위 집중 측정

### 4단계 — 피로 균열 중점 검사 부위

- 가로보-거더 연결부 용접부
- 수직 보강재(Stiffener) 용접 지단부 (weld toe)
- 주거더 하부 플랜지 (인장측)
- 점검 이력 없는 용접 이음부

## 합격 기준

| 검사 항목 | 합격 기준 |
|---|---|
| 부식 등급 | Ri 0 ~ Ri 2 (면적 0.5 % 이하) |
| 강재 두께 감소 | < 5 % |
| 용접부 균열 | 표면 균열 없음 (MT/PT 음성) |
| 하중 작용 변형 (처짐) | 설계 허용처짐 이내 |
| 출입 전 산소 농도 | ≥ 18 % |
