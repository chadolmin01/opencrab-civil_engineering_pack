## 3. 반발경도법 (Schmidt Hammer)

### 3.1 시험 원리

- 스프링으로 충격 해머를 발사하여 콘크리트 표면 타격 후 반발량(R value) 측정
- R값과 압축강도(fck) 간 경험식으로 강도 추정 (보조 수단)

### 3.2 시험 절차 (KS F 2730)

1. 시험면 표면 거칠기 제거 (카보런덤 사포 사용)
2. 타격 방향: 수평·수직·경사 → 방향 보정 계수 적용
3. 1개소 16회 타격, 이상값(±6 이상 편차) 제거 후 평균
4. 최소 3개소 이상 측정 후 통계 처리

### 3.3 강도 추정식

한국 표준식 (국토안전관리원 적용):
- **fck = α × R^β** (α·β: 콘크리트 종류별 계수)
- 일반 콘크리트: fck(MPa) ≈ 1.7 × R^1.4 (수평 타격 기준, 보정 전)
- 실용 근사: R = 30 → fck ≈ 21 MPa, R = 40 → fck ≈ 34 MPa, R = 50 → fck ≈ 50 MPa

### 3.4 방향 보정 계수

| 타격 방향 | 보정값 (R에 가산) |
|---------|------------|
| 수평 (0°) | 기준 (0) |
| 상향 (+90°) | -3.0 |
| 하향 (-90°) | +3.0 |
| 상향 (+45°) | -1.5 |
| 하향 (-45°) | +1.5 |

### 3.5 판정 기준

| 추정 압축강도 / 설계기준강도 비율 | 판정 |
|--------------------------|-----|
| 1.0 이상 | 이상 없음 (보조 참고) |
| 0.85~1.0 | 추가 조사 (초음파·코어) 권고 |
| 0.85 미만 | 정밀 조사 필수, 등급 하향 검토 |

**주의:** 반발경도 단독 판정 금지. 반드시 코어 시험 또는 초음파속도와 병행.

## 4. 초음파속도법 (UPV; Ultrasonic Pulse Velocity)

### 4.1 시험 원리

- 초음파 펄스를 콘크리트에 투과시켜 전달 시간 측정
- 전달 속도(V = 거리/시간)로 균질성·내부 결함 판단
- 강도 추정은 반발경도와 병용 (SonReb 복합법)

### 4.2 측정 방법

| 방법 | 적용 | 설명 |
|-----|-----|-----|
| 직접법 | 양면 접근 가능 | 탐촉자 맞댐, 가장 정확 |
| 반직접법 | 한 면·인접 면 | 90° 각도 |
| 간접법 (표면법) | 한 면만 접근 | 정확도 낮음, 박락·공동 탐지 보조 |

### 4.3 초음파속도 판정 기준 (KS F 2731)

| 초음파속도 (m/s) | 콘크리트 상태 | 등급 |
|--------------|-----------|-----|
| ≥ 4,500 | 우수 (Excellent) | A |
| 3,500~4,500 | 양호 (Good) | B |
| 3,000~3,500 | 의심 (Doubtful) | C |
| 2,000~3,000 | 불량 (Poor) | D |
| < 2,000 | 매우 불량 (Very poor) | E |

### 4.4 SonReb 복합법 (반발경도 + 초음파속도)

- 초음파속도 V와 반발경도 R을 결합하여 강도 추정 정밀도 향상
- 일반식: fck(MPa) = C₁ × V^C₂ × R^C₃ (C₁·C₂·C₃: 지역 보정 계수)
- 국내 기준: fck = 0.0142 × V^0.85 × R^1.25 (단위: V [km/s], R [-])

## 5. 코어 채취 및 압축강도 시험

### 5.1 채취 기준 (KS F 2422)

| 항목 | 기준 |
|-----|-----|
| 코어 직경 | φ100 mm 표준 (최소 φ75 mm) |
| 코어 높이/직경 비 (H/D) | 1.0~2.0 (표준 2.0) |
| 채취 간격 | 구조물 부재당 최소 3개 이상 |
| 채취 위치 | 주근·전단 철근 회피, 대표 부위 |
| 압축 방향 | 코어 축방향 가압 |

### 5.2 강도 보정 계수

| H/D 비 | 보정 계수 (실측강도 × 계수 = 보정 강도) |
|-------|----------------------------------|
| 2.0 | 1.00 (기준) |
| 1.75 | 0.98 |
| 1.50 | 0.96 |
| 1.25 | 0.93 |
| 1.00 | 0.87 |

### 5.3 판정 기준

| 코어 압축강도 / 설계기준강도(fck) | 판정 |
|---------------------------|-----|
| ≥ 0.85 fck 이상 (평균) | 합격 |
| 0.75~0.85 fck | 요주의 — 추가 조사 및 C등급 검토 |
| < 0.75 fck | 불합격 — D등급 하향, 긴급 보강 검토 |

**KCI 기준:** 3개 코어 평균 ≥ 0.85fck이고, 개별값 ≥ 0.75fck 시 합격

## 6. 중성화(탄산화) 깊이 시험

### 6.1 시험 원리

- 콘크리트 내 수산화칼슘(Ca(OH)₂)이 CO₂와 반응하여 탄산칼슘(CaCO₃) 생성 → pH 12.5 → 9 이하로 저하
- 페놀프탈레인 지시약 (1% 에탄올 용액) 살포 시: 미중성화(pH ≥ 9.5) = 적색, 중성화(pH < 9.5) = 무색

### 6.2 시험 절차 (KS F 2456)

1. 코어 채취 또는 국소 파쇄로 신선 단면 노출
2. 먼지·분진 제거 후 페놀프탈레인 용액 살포
3. 30초 내 변색 경계선 깊이 측정 (3개소 이상, mm 단위)
4. 평균 중성화 깊이 산출

### 6.3 중성화 속도 계수 (√t 법칙)

- 중성화 깊이 d = A × √t (mm), A: 중성화 속도 계수 (mm/√year)
- 잔존 내용년수 = [(피복두께 / A)² - 현재 경과연수]

### 6.4 판정 기준

| 중성화 진행 상태 | 기준 |
|-------------|-----|
| 중성화 깊이 < 피복두께 × 0.5 | 안전 (A~B) |
| 중성화 깊이 = 피복두께 × 0.5~1.0 | 주의 (C) |
| 중성화 깊이 ≥ 피복두께 (철근면 도달) | 위험 (D) |
| 중성화 깊이 > 피복두께 (철근 관통) | 매우 위험 (E) |

**일반 환경 중성화 속도 계수 기준값:**

| 환경 조건 | A값 (mm/√year) |
|---------|--------------|
| 옥내 건조 환경 | 3.0~5.0 |
| 옥외 노출 (빗물 차단) | 2.0~4.0 |
| 옥외 노출 (빗물 접촉) | 1.5~3.0 |
| 해양·고습도 환경 | 1.0~2.5 |

## 7. 철근 부식 전위차 측정

### 7.1 시험 원리 (ASTM C876)

- 반전지(Half-cell) 법: 콘크리트 표면과 내부 철근 간 전위차 측정
- 부식 진행 시 산화반응으로 전위가 낮아짐 (음의 방향)
- 측정기기: CSE(Copper-Copper Sulfate Electrode) 기준전극 사용

### 7.2 전위차 판정 기준 (ASTM C876 기준)

| 전위차 (CSE 기준) | 부식 가능성 |
|--------------|---------|
| > -200 mV | 부식 가능성 90% 이상 없음 (안전) |
| -200 ~ -350 mV | 부식 가능성 불확실 (주의) |
| < -350 mV | 부식 가능성 90% 이상 (위험) |
| < -500 mV | 활성 부식 진행 중 (매우 위험) |

**주의:** 수분 함유량이 낮으면 전위가 높게 나와 부식 과소 평가 위험. 습윤 상태에서 측정 권장.

## 8. 염화물 이온 분석

### 8.1 채취 방법

- 깊이별 분쇄 분말 채취 (0~10, 10~20, 20~30, 30~50, 50~70 mm 구간)
- 화학적 분석: KS F 2713 (Volhard법 또는 전위차 적정법)

### 8.2 허용 기준

| 위치 | 허용 한계 |
|-----|---------|
| 일반 환경 (내부 철근 위치) | ≤ 1.2 kg/m³ |
| 해양 환경 (내부 철근 위치) | ≤ 0.6 kg/m³ |
| 프리스트레스트 콘크리트 (긴장재 위치) | ≤ 0.3 kg/m³ |

### 8.3 염화물에 의한 부식 임계값

| 염화물 농도 | 부식 시작 가능성 |
|---------|------------|
| < 0.4 kg/m³ | 부식 시작 없음 |
| 0.4~1.2 kg/m³ | 부식 시작 가능 (임계범위) |
| > 1.2 kg/m³ | 부식 진행 중 가능성 높음 |

## 9. 시험 결과 종합 판정 절차

```
1단계: 반발경도 + 초음파속도 → 강도 추정 (1차 스크리닝)
    ↓
2단계: 의심 부위 코어 채취 → 실제 압축강도 확인 (절대값)
    ↓
3단계: 중성화 깊이 + 철근 부식 전위차 → 내구성 평가
    ↓
4단계: 염화물 분석 → 장기 내구성 예측
    ↓
5단계: 종합 판정 → 안전등급 결정 + 보수·보강 방안 제시
```

## 11. 비파괴 시험 결과 보고서 구성

1. 시험 개요 (시설물 현황, 시험 목적, 적용 기준)
2. 시험 위치 도면 (측정 개소 번호 표기)
3. 반발경도 측정 결과 (개소별 R값·추정강도 일람)
4. 초음파속도 측정 결과 (개소별 V값·상태 판정)
5. 코어 압축강도 시험 결과 (개소별 수치·설계기준강도 대비)
6. 중성화 깊이 측정 결과 (개소별·잔존 내용년수 추산)
7. 철근 부식 전위차 결과 (해당 시 부식 위험 구역 표기)
8. 염화물 이온 분석 결과 (깊이별 농도 그래프)
9. 종합 판정 및 내구성 평가
10. 보수·보강 권고 사항
