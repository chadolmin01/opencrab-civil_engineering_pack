# 정밀안전진단 타음법(해머 타음 검사) 콘크리트 박리·공동 진단 가이드 — 출처: 도메인 지식 / 시설물 안전법 정밀안전진단 세부 지침 / KS F 0806 기반 — 수집일: 2026-05-28

## 개요

타음법(Hammer Sounding, 打音法)은 검사 해머로 콘크리트 표면을 두드려 발생하는 음향(탁음/청음)으로 박리층·공동·들뜸 여부를 판별하는 비파괴 검사 기법이다. 시멘트 페이스트와 골재 경계면 박리, 피복 콘크리트 들뜸, 거푸집 탈락부 공동, 동결융해·AAR에 의한 층간 분리를 빠르고 간단하게 식별할 수 있다. 터널 라이닝·교량 바닥판 하면·교각·옹벽 등 광범위한 표면 진단에 적용한다.

---

## 정량 기준

### 음향 판별 기준

| 음향 특성 | 판정 | 조치 기준 |
|---|---|---|
| 청명한 금속음 (맑고 높은 음) | **밀실 (합격)** | 이상 없음 |
| 둔탁한 濁音 (저음, 울림 없음) | **경계 (주의)** | 범위 마킹, 추가 정밀 조사 |
| 공명하는 공동음 (hollow sound) | **공동·박리 (불합격)** | 즉시 범위 측정·보수 계획 |

### 박리 판정 면적 기준

| 박리·공동 면적 비율 | 판정 | 조치 |
|---|---|---|
| **< 5 %** | 경미 (D등급 이상 유지) | 모니터링 |
| **5 ~ 15 %** | 중간 | 단면 보수 (패칭) |
| **15 ~ 30 %** | 심각 | 전면 오버레이 또는 교체 |
| **> 30 %** | 위험 (E등급 고려) | 즉시 보수, 사용 제한 검토 |

### 박락 위험 판단

| 위치 | 박락 위험 한계 |
|---|---|
| 교량 하부 슬래브 (차량·보행자 위) | 공동 크기 **0.04 m²** 초과 → 즉시 접근 통제 |
| 교각 기둥 | 박리 깊이 피복 두께 **50 %** 초과 → 구조 안전성 평가 의뢰 |
| 터널 라이닝 | 공동 면적 **0.1 m²** 또는 두께 감소 **30 %** → 즉각 조치 |

## 검사 절차

### 1단계 — 검사 준비

1. 검사 해머 선택: 표면 스케일 조사용 **150 g (5 oz) 해머**, 두꺼운 슬래브·교각 **300~500 g 해머**
2. 격자 구획 설정: 검사 면적을 **0.5 m × 0.5 m** 격자로 나누고 격자 번호 부여
3. 배경 소음 확인: 작업 소음이 클 경우 청음 정확도 저하 → 조용한 시간대 작업 또는 전자 청음기 사용

### 2단계 — 타음 검사 실시

1. 해머를 **일정 타격 강도**로 격자 내 3~5개소 타격
2. 음향 특성 분류: 검사원 2인 이상 독립 청음 후 합의 판정 권장
3. 공동·박리 의심 구역 마킹: 형광 스프레이 또는 분필로 경계 표시
4. 격자별 판정 결과 도면에 기록 (밀실/주의/공동 구분 기호)

### 3단계 — 범위 확정 및 정량화

1. 공동 경계부 집중 타음으로 정확한 면적 산출
2. 줄자·격자 면적 계산으로 공동 면적(m²)·비율(%) 산정
3. 박리 깊이 추정: 드릴링 코어(φ50 mm) 1개소 이상 채취하여 두께 측정

### 4단계 — 박락 위험 평가

1. 천장면·하부면 박리 구역: 낙하 시 위험도 평가 (위치·크기·무게 추정)
2. 충격탄성파(IE) 또는 Ground Penetrating Radar(GPR) 병행: 공동 깊이 및 3차원 범위 확인
3. 즉각 조치 필요 구역: 안전 울타리 설치 및 접근 통제 실시

## 합격 기준

| 검사 항목 | 합격 기준 |
|---|---|
| 타음 판정 | 청음(밀실) — 공동음 없음 |
| 공동·박리 면적 비율 | < 5 % (해당 검사 구역) |
| 박리 깊이 | 피복 두께의 50 % 미만 |
| 천장·하부 박리 크기 | 1개 공동 ≤ 0.04 m² |
