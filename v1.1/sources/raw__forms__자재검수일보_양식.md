# 자재검수일보 (현장 자재 반입 검수일보) — 발행기관: 국토교통부 건설사업관리 표준 / LH 품질관리지침 / 대한건설협회 — 출처: https://m.yesform.com/doc/form/129470 (자재검수 요청서), https://m.yesform.com/doc/form/335134 (주요 자재검수서), https://pumjil.lh.or.kr/ (LH 품질관리지침) — 수집일: 2026-05-28

## 개요
건설현장에 반입되는 자재(주요자재·일반자재·가설자재)에 대해 시공자가 검수 후 감리원에게 확인을 받는 일일 검수 양식.
KCS(국가건설기준) 및 LH 품질관리지침에 따라 주요자재는 사전 자재사용보고(공급원 승인) 후 반입.

## 표준 머리행
- 일자(검수일): ____________ (YYYY-MM-DD)
- 공사명: ____________
- 시공사: ____________
- 감리단: ____________
- 발주처: ____________

[1. 일반정보]
- 현장명: ____________
- 검수일자: ____________
- 검수자: ____________
- 품질관리자: ____________
- 천기: 맑음/흐림/비/눈 + 기온 ____ ℃

[2. 자재 정보 (자재별 1행, 다수 행 입력 가능한 표 형식)]
- 품명: ____________
  - 입력 타입: 텍스트
  - 예시값: 레미콘(25-24-150) / 철근(SD400 D16) / PHC파일(직경600 길이15m)

- 규격: ____________
  - 입력 타입: 텍스트
  - 예시값: D10/D13/D16/D19, 50×100×3000

- 단위: ____________
  - 입력 타입: enum (m³ / m / ton / 본 / 매 / EA / kg)

- 반입수량: ____________
  - 입력 타입: 숫자
  - 예시값: 50

- 발주수량(누계): ____________
  - 입력 타입: 숫자

- KS 유무: 있음 □ / 없음 □ / 해당없음 □
  - 입력 타입: 체크박스

- 제조사(공급원): ____________
  - 입력 타입: 텍스트
  - 예시값: ○○레미콘, △△제철

- 차량번호/송장번호: ____________
  - 입력 타입: 텍스트

- 반입시간: ____________ (HH:MM)

- 사전승인 여부 (자재사용보고/공급원 승인): 승인 □ / 미승인 □
  - 입력 타입: 체크박스 + 승인번호

[3. 검수 항목 — 시공자 자체검수]

- 항목 3.1: 외관 검사 (균열, 손상, 변형, 부식)
  - 검사기준: 시방서, 자재별 KS 표준
  - 입력 타입: 적합/부적합 체크
  - 검수결과: ____________

- 항목 3.2: 수량 확인 (송장 대비)
  - 입력 타입: 적합/부적합 + 차이
  - 검수결과: ____________

- 항목 3.3: 규격·치수 확인 (랜덤 측정)
  - 검사기준: KS 허용오차
  - 입력 타입: 측정값
  - 측정값: ____________

- 항목 3.4: 표시사항 확인 (KS 마크, 제조일, 등급, 로트번호)
  - 입력 타입: 적합/부적합
  - 표시 내용: ____________

- 항목 3.5: 시험성적서(Mill Sheet / 출하증명서) 첨부
  - 검사기준: 자재별 KS 시험 요구 항목
  - 입력 타입: 첨부 유무
  - 첨부: 예 □ / 아니오 □

- 항목 3.6: 운반·보관 상태 (방수, 분리적치)
  - 입력 타입: 적합/부적합

[5. 종합판정]
- 검수 결과: 합격 □ / 조건부 합격 □ / 불합격(반품) □

- 발주자 (사용 검수 시): ____________ (인) [해당시]

## 참고 — 자재검수 절차 (한국 표준)
1. 시공자 자재사용계획서/공급원 승인 신청 (사전)
2. 감리원·발주자 공급원 승인 (사전)
3. 자재 반입 (송장 확인)
4. 시공자 자체검수 (시공자 → 본 일보 작성)
5. 감리원(담당/책임감리원) 검수 확인
6. 부적합 시 반품 처리, 적합 시 사용 승인
7. 주요자재 시험 (KS/KCS 기준) — 별도 시험성적서 첨부
